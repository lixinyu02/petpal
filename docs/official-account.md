# 桌面端使用 ChatGPT 官方账号

Windows、Ubuntu 客户端可通过官方 Sign in with ChatGPT 授权，使用当前账号返回的套餐模型。原有 API 连接保留，可在模型选择器中分别选择。

## 登录与使用

1. 将客户端连接到其内置的**本机服务**，先登录这台电脑的小伴账号。连接远程中央服务时，官方账号设置会提示切换服务；网页登录和 Android 没有这个原生登录入口。
2. 打开「连接与设置 → 模型连接」，在「ChatGPT 官方账号」点击「使用 ChatGPT 登录」。在系统浏览器的官方页面登录并确认授权，完成后回到客户端。等待期间可点击「取消登录」。
3. 查看返回的官方模型目录。目录由当前官方账号和授权决定，不固定写死模型名称；显示「图文」的模型可接收图片。授权成功、目录可见和某次推理成功是三个独立状态。
4. 在 Chat 或 Agent 的模型选择器选择对应的 `ChatGPT · …` 模型。可保存新对话的默认模型；已有 API 对话不会因此改用官方模型。连接测试会实际发送简短请求，使用所选模型额度。

Agent 沿用现有执行电脑、项目目录、权限、审批与队列入口，Chat + Agent 也可以选择官方模型。普通用户仍只能选择自己登录的 PC；官方账号登录不会扩大设备访问权限。Agent 需要内置 Codex 可用，图片能力以所选模型目录为准。

同一个小伴用户可添加或切换多个官方账号。退出或切换身份会停止相关官方请求并撤销旧排队授权，旧任务不会自动改用另一账号或第三方 API。继续已有会话时会建立新身份的执行线程；必要时在确认任务状态后手动恢复队列。

## 额度与用量

「官方额度与用量」展示客户端**实际观察到的请求状态**，包括最近验证时间、模型，以及本次连接已完成的请求数和输入／输出／合计 Token。只有官方返回已完成响应才累加请求；Token 只累加响应中实际提供的有效 `usage` 字段，不按文字长度估算。未返回的字段不增加计数，零值不能证明没有消耗额度。

这些统计按当前本机官方身份保存在内存中，重启客户端、退出、切换账号或改变授权身份后重新计数。同身份普通令牌续期、刷新模型或刷新状态不会清空计数。一次 Agent 任务可能包含多次模型请求，因此任务数不等于请求数。

当前官方公开 SIWC 接口没有提供套餐剩余量或精确恢复时间的查询接口。页面不计算剩余百分比，也不把登录或刷新目录成功标为「额度可用」。真实套餐用量和限制以[官方用量页面](https://chatgpt.com/settings/usage)为准。

| 页面状态 | 含义与处理 |
| --- | --- |
| 尚未验证 | 尚无本次身份的成功请求证据；发送一次实际请求后才能验证。 |
| 最近验证可用 | 最近收到真实的已完成响应，不保证下一次请求一定成功。 |
| 套餐额度已受限 | 官方返回套餐／应用限额错误；暂停发出新的官方模型请求。确认官方额度恢复后，点击「额度恢复后重试」，再手动发送任务。 |
| 暂时不可用 | 官方用量或账号／工作区暂时无法检查。稍后手动重试；客户端不自动重放任务。 |
| 账号或工作区暂不具备使用资格 | 官方返回账号／工作区不具备资格。检查官方限制，或选择／添加其他符合资格的账号；不要反复对当前账号重新授权。 |

「刷新状态」只重新读取客户端观察结果，不代表已向官方核查剩余额度。「额度恢复后重试」仅解除本地限额暂停、恢复到尚未验证，保留本次计数；它不会证明额度已经恢复，也不会自动恢复 Agent 队列或补发失败任务。已在限额报错前发出的请求可能稍后完成，其真实用量仍计入统计，但不会自动解除限额暂停。

## 私有存储与故障处理

官方授权凭据按本机小伴用户隔离，保存在主进程的私有存储中，不进入共享模型配置、聊天页面或远程执行电脑。管理员也不能查看其他用户的官方模型或凭据。此功能不读取宿主 `~/.codex/auth.json`，不覆盖系统已有 Codex 登录；登录、取消、切换和退出仅通过可信桌面窗口处理。

模型目录刷新暂时失败时，新模型选择暂不可用；同身份已授权的执行任务可继续。身份变化会立即撤销旧授权。若提示私有存储或系统密钥环不可用，检查该电脑的客户端私有目录权限和密钥环后重启；不要将凭据文件复制进项目或提交 Git。

## 验证边界

本轮授权、网关、模型、Chat／Agent、队列、审查、图片与账号隔离回归已通过。Windows x64 与 Ubuntu 24.04 WSLg x64 的原生源码客户端已实际启动，登录门禁、真实 IPC 和官方账号入口通过；这不等于独立 Ubuntu 物理电脑或新安装包验收。**真实用户官方 OAuth 授权及套餐推理仍待完成**；不能用目录替身或自动化测试代替真实账号准入和推理验证。详见[本轮验收记录](workflow/2026-10-15-official-account-acceptance.md)。本轮尚未发布新版正式安装包。
