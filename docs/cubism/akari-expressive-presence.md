# V9 神态与语境动作

V9 是基于 V8 真实骨架的动作包升级：MOC、纹理、物理、图层元数据与原有九组 motion 逐字节复用，保留人物脸部和刘海比例。没有重新导出 MOC，也没有新增假参数。来源哈希见 [来源记录](akari-expressive-presence-provenance.json)。

## 新增动作

| 原生组 | 时长 | 使用场景 |
| --- | --- | --- |
| Curious | 1.6 秒 | 好奇侧头、轻轻探看 |
| Think | 1.6 秒 | 思考停顿、犹豫 |
| Listen | 1.9 秒 | 进入倾听，微微前倾 |
| Surprise | 1.25 秒 | 惊讶时轻微后退及收手 |
| Reassure | 1.9 秒 | 明确安慰句、放松或温柔回应 |
| Wink | 1.35 秒 | 调皮语义，单次右眼短眨 |
| Doze | 2.4 秒 | 困倦时短暂低头闭眼，再恢复 |

与现有九组合计十六组，符合原资源数量限制。新曲线只操作已有头部、身体、合手、衣袖和局部闭眼参数，不写嘴型和整脸表情贴片。待机原有看向一侧、慢眨眼、淡淡微笑后，新增双眨眼、小幅侧头和身体轻放松；首个动作等待 8.5 秒，后续保持至少十秒的安静间隔。

## 表情及调度

担心、委屈和犹豫低权重映射到已有 Sad 局部表情，释然、温柔、害羞及微笑映射到 Warm。采用最大强度保留直接通道，再只选择一个主贴片，避免相互叠脸。这里是现有局部图层的神态组合，不是新增独立眉毛或眼球几何。

思考／倾听仅在阶段入口触发一次，同一阶段的 ASR 草稿或 utterance ID 变化不重播。每次成功动作带稳定的 `gestureCueId`，相同动作可以在新的有效 cue 再次播放。手动互动优先，切阶段、停止、缓冲、隐藏、休息和减少动态清理对应来源；语音的 neutral／负面权威信息继续优先。负面流式文本到来时会收起原先的开心或调皮自动动作。

原生右眼 Wink 不叠加同一眼的 performance 闭合，左眼保留自然眨眼，实际口型最后独立应用。动作文件最多三路并行读取，保持逐个原生解码；失败取消同批并等待其完成，成功读取不再事后 abort。

## 重建和限制

运行 `node scripts/authoring/prepare-akari-expression-motions.mjs` 仅生成 V9。它验证 V8 来源及真实参数范围，九旧组原样保留；编辑源仍在 `outputs/avatars/akari-cubism-v8/`，原 PSD 位于 V7，详见 [V8 作者合同](akari-hand-gestures.md)。

手部仍是双手交握下的小幅共同位移，不能独立伸指或完整挥手。眼睑仍用局部闭眼图层，不是连续眼睑或独立眼球。新增原生 Wink 的右眼闭合仅在 Cubism 生效；旧 fallback 保留调皮脸和轻侧头、原有招呼眨眼，不具备该新原生单眼动作。官方 Editor roundtrip 未验证。网页结果和测试范围见 [验收记录](expressive-presence-validation.md)。
