# 0.4 账号与语音配置

本文描述 0.4 源码中的账号、模型授权、语音设置和本机设备偏好。当前交付状态以 [0.4 验收记录](acceptance-0.4.md) 为准；[0.3 验收](acceptance.md) 和既有安装包保留其原始证据。

## 账号和模型

主机 owner 保留桌面配对方式及主机 Codex 使用权。管理员创建账号、设置或重置密码、停用成员并分配可使用的模型连接；不开放自行注册。普通成员通过账号密码登录，只能访问自己的会话、伙伴设置、默认模型和语音配置。管理员维护模型地址与密钥；成员的模型授权不包含主机 Codex 身份。

在「连接与设置 → 账号」查看当前身份。主机管理员可在这里创建成员并选择授权模型；成员通过「登录你的个人服务 → 账号密码」填写服务地址、账号和密码。桌面「使用本机主账号」返回本机 owner；手机访问仍要求可信 HTTPS 服务地址。主机配对令牌与账号登录会话不同：退出会撤销当前账号会话，主机配对令牌继续归 owner 使用。

停用账号、重置密码或撤销模型授权会使相应会话或任务失效。退出登录撤销当前登录会话。切换账号时，界面应取消旧请求和系统朗读、清空旧聊天，并重新加载新账号偏好；不能将旧账号的待同步设置发送给新账号。

旧单用户状态迁移到主机 owner，迁移前保留备份。账号密码以独立盐的 scrypt 哈希保存，服务会话只保存令牌摘要和有效期。模型与语音服务的 API Key 仍由个人服务以本地文件保存，API 回读只包含 `hasApiKey`。这不是云端账号运营或多进程数据库方案。

## 语音设置的当前边界

打开「连接与设置 → 语音与设备」。「声音与倾听」为当前账号保存连接资料。当前可运行的朗读仍是设备的系统语音；选择远程 TTS、远程 ASR 或浏览器识别不会发送音频、文本或自动申请麦克风权限。

| 项目 | 初始值 | 可配置内容 |
| --- | --- | --- |
| TTS | `system`，语速 `1` | `system` / `remote`、服务地址、模型 ID、音色 ID、语速、API Key |
| ASR | `disabled`，语言 `zh-CN` | `disabled` / `browser` / `remote`、服务地址、模型 ID、语言、API Key |

远程模式要求完整的服务地址和模型 ID。语速范围为 `0.25–4`；音色可以留空，识别语言留空表示预备由服务检测。地址最多 2048 字符，模型和音色最多 160 字符，语言最多 35 字符，密钥最多 8192 字符。

服务地址只支持 HTTP(S)，不接受 URL 内凭据、查询参数、片段或空白。公网地址要求 HTTPS；HTTP 仅允许 localhost、其子域、`.local`、私有 IPv4、IPv6 回环 / ULA / link-local 地址。这是连接资料校验，不会在保存时尝试连接。

API Key 留空会保留旧值。「清除已保存的密钥」显式删除旧值。更换服务地址时，必须重填密钥或明确清除，避免把旧服务的凭据带到新地址；不能在一次请求里同时清除和替换密钥。规范化后仅大小写、默认端口或结尾斜线的等价地址不视为换址。

`GET /api/voice` 与 `PATCH /api/voice` 根据当前登录凭据定位账号，body 中的用户 ID 不能改变所属账号。回读固定包含：

```json
{"runtime":{"tts":"system","asr":"not-connected","remoteConfiguredOnly":true}}
```

「已保存」仅表示配置保存成功，不表示远程语音已经接通。

## 本机麦克风、摄像头和扬声器

同一页的「输入与输出设备」提供设备选择和本地测试：

1. 点击「刷新设备」，选择系统默认设备或列表中的具体设备。未授权时，浏览器可能隐藏设备名称，已保存的选择会显示「未授权或当前未连接」。
2. 点击「测试麦克风」后，按浏览器或系统提示授权。输入电平条显示当前信号，测试不录音、不上传，也不通过扬声器回放。
3. 点击「预览摄像头」后授权，即可在当前页面查看实时画面。预览不拍照、不录制、不上传。
4. 选择扬声器并点击「播放测试音」，播放一段约 280 毫秒的本地短音。页面显示播放结束不等于已经听到声音，需自行确认实际输出。
5. 点击「停止设备测试」结束当前测试。更换设备、离开页面、隐藏窗口或切换账号也会结束输入测试并释放轨道；每次只运行一种测试。

扬声器选择只影响支持输出路由的网页音频和测试音。**现有系统 TTS 始终跟随系统默认输出**：浏览器的 `speechSynthesis` 没有可供这里调用的 `setSinkId` 接口。如需改变系统朗读的扬声器，请在操作系统的声音设置中更改。浏览器不支持网页输出路由时，选择框不可用，测试音使用系统默认输出。

Web 设备采集需要 HTTPS 或本机 localhost。Windows/Ubuntu 桌面仅向可见主窗口中的本地顶层页面开放相机、麦克风及受支持的输出选择；悬浮伙伴和子框架不获此权限。Android 主界面通过系统权限提示请求相机和麦克风，悬浮窗仍拒绝媒体权限。实际可用设备、授权提示及音频路由由系统和 WebView 决定。

设备 ID 属于当前浏览器及其权限环境，不会作为跨设备设置上传后端。偏好按照个人服务 instanceId 和用户 ID 隔离，初始三个设备选择均为空字符串，表示系统默认。只保存 `microphoneId`、`cameraId`、`speakerId`，不保存设备名称、登录令牌或其他连接信息。

读取或写入本地存储失败时，本次页面仍可保留内存中的选择。账号相关组件卸载后，旧控制器不可再写入；选择不会从旧的无账号存储迁移到其他账号。设备枚举可能因权限不足而隐藏 ID 或名称，因此不能据此自动清空已有选择；只有同类型设备中已经出现可用 ID 和名称时，才可提示已选设备不可见并选择系统默认。

设备测试与远程 TTS/ASR 配置相互独立。保存远程服务资料不会开始测试；允许本地麦克风测试也不表示已开启语音识别或向提供商发送音频。

## 实现与证据

- `server/voice.mjs` 是无 HTTP / 音频副作用的配置模块；字段校验、密钥处理和公开回读都采用白名单。
- `src/media/device-preferences.mjs` 是本地设备偏好模块，不调用浏览器媒体 API 或后端。
- 账号隔离、迁移和路由由后端实现；媒体权限、测试和停止由前端生命周期负责。
- 模块测试不能替代真实浏览器、扬声器听音、摄像头图像或 Android / Ubuntu 目标设备验收。
