- Node 自动测试 204/204，通过账号隔离、模型、Codex、媒体与新增更新协议/桌面交接回归。
- 发布工具额外 17/17 测试通过（签名 9、公开源码审计 8），源码打包边界检查通过。Git index 审计扫描实际暂存 blob，包括二进制和 JSON 转义私钥标记。

- Android `:app:compileDebugJavaWithJavac :app:testDebugUnitTest` 通过，17 项 JVM 测试无失败；Web 资源已用 `cap sync android` 同步。未安装 APK 或启动系统安装器。
- Chrome 检查“软件更新”入口、0.6.0 客户端版本、默认仓库、缺公钥提示、非法仓库错误及重新读取。通过临时站点版本文件验证 Web 已部署新版才显示刷新入口，随后恢复真实版本。移动端有效 CSS 宽度与 scrollWidth 均为 391，无横向溢出；Playwright 截图超时后通过 Chrome 插件截图接口取得移动端截图；桌面与移动截图均保存在本地 evidence。

Windows 交接打开新版便携程序并保留旧 EXE；Ubuntu 仅显示已校验归档；Android 核对包名、版本、安装签名后交系统安装器；Web 使用已部署版本刷新。不能将这些路径描述为四端均已完成自动安装。

更新源使用公开 GitHub Releases 与 Ed25519 签名清单，默认没有发布公钥，不联网下载未知发布。公钥、正式同签名 APK 与各端发布包仍由发布者准备。当前未生成正式签名私钥，未创建二进制 Release，未改变任何设备权限。
