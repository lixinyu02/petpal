# Android 官方账号与应用代理

Android 客户端可在手机本机保存 ChatGPT 官方授权，读取当前账号的模型目录并请求官方 Responses 接口。手机不内置 Codex CLI；Agent 仍在用户选定的电脑运行。后端需要包含 `/api/mobile-official/*` 新接口，旧服务不能登记手机模型。

## 使用

1. 在 Android 小伴登录自己的小伴账号。
2. 如需代理，在连接设置的「应用代理」导入 Clash YAML 文件、粘贴配置，或填写自己的 HTTPS 配置直链，再启用。可选择节点并保存登录后自动启用偏好。
3. 在模型设置的「ChatGPT 官方账号」点击登录，在系统浏览器的官方页面确认授权，回到小伴后检查目录。手机连接、账号登录和真实完成一次推理是独立状态。
4. 在 Chat 或远程 Agent 选择 `ChatGPT · …（手机）` 模型。语音聊天和 Chat 派发 Agent 复用同一模型链路；执行电脑、权限和项目目录沿用原入口。

官方 access / refresh / ID token 只在 Android 原生内存和 Keystore 加密的私有文件中，不返回聊天页面、中央服务或执行电脑。模型请求由手机实际发送；后端只处理本来已保存在该账号下的上下文、工具与回复流。

## 账号与在线边界

账号配置按 **后端来源地址 + 后端实例 + 小伴用户** 隔离。用另一个域名或 IP 连接同一后端，也不会自动继承旧地址下的官方授权。切换小伴账号或服务会立即撤销原生绑定。切换或退出官方账号会停止旧模型请求，不替换模型重试任务。

沿用桌面端按小伴账号隔离的官方模型权限：手机在线期间，同一小伴账号可使用该手机提供的模型；其他小伴用户和管理员不可借用。登记模型所用的登录会话失效、掉线租约到期或手机退出时，后端撤销临时能力。Android 被系统挂起或结束后，不保证手机模型继续在线；没有系统级常驻 VPN。

页面展示当前官方身份本次登录的本机累计完成请求数与上游实际返回的 Token 用量。重启后可保留该身份的统计；切换身份或退出重新计数。它不表示精确套餐余量。限额暂停后点击重试仅解除本地暂停并保留计数，不自动补发请求。真实额度以官方用量页面为准。

## 仅小伴代理

内置 Mihomo 1.19.32 Android 核心支持 ARM64、ARMv7、x86_64。实际 ELF 声明 API 34，因此这项代理功能要求 **Android 14+**，并需要支持应用代理覆盖的 Android System WebView；其他功能保留原最低系统要求。64 位核心的 ELF 段为 16 KiB 对齐。小米手机按实际系统和架构识别，不按型号猜测版本。

代理只覆盖小伴的 WebView 和显式原生网络请求，包括模型、token 交换和刷新、服务连接、更新与任务提醒。局域网和回环直连；不申请 VPN、不改系统代理、DNS 或其他应用。内核从 APK 的只读安装目录启动，不能下载任意替换核心执行。

**外部 Chrome / Custom Tabs 不使用小伴代理。** 官方 SIWC 目前明确的是系统浏览器授权，不能把 App 内 WebView 当成已受支持的登录替代方式。授权网页需要浏览器自身网络可达；授权后的模型和令牌请求可以在 App 内走代理。

监听端口仅绑定 `127.0.0.1`，控制器使用随机密钥。Android 回环并非按 UID 隔离的通道，其他本机应用若主动配置该端口也可能连接；这里的「仅小伴」指应用显式使用代理，不表示系统按应用 UID 隔离端口。

配置导入不接受文件型 provider 或任意本地证书路径；HTTPS provider 的缓存固定在当前配置私有目录。启用失败或内核退出会清理小伴代理覆盖。关闭设置面板不会停止正在使用的代理；退出账号或切换服务会停止。

## 构建与验收

`scripts/build-android.ps1` / `.sh` 会准备并校验固定版本的三种 Android 核心、许可和完整对应源码；APK 构建缺少它们时明确失败。生成的 `jniLibs` 和资源不进入 Git；来源、哈希与获取脚本保留。详见 `android/mihomo/manifest.json` 与 `SOURCE-NOTICE.txt`。

本次测试记录见 [验收说明](workflow/2026-10-15-android-official-account-acceptance.md)。模拟器和合成上游测试不等于小米 ARM64 真机授权或真实套餐推理成功。正式下载与更新清单需另行发布，不能用调试测试包冒充正式版。
