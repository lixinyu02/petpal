# 微表演扩展验收

2026-09-30，issue-41。已更新网页；没有重新打包原生客户端。

## 本轮变化

- 新增犹豫、困倦、期待、委屈、温柔五种神态，复用现有八张贴图，通过眼眉、视线和不透明眼形压缩区分。
- 新增探身倾听、轻轻缩肩、礼貌低头、侧身探看、轻摆、困倦低头六种单次动作。肩部局部形变幅度有界；DOM 降级使用更保守的整体轻抬，未实现独立手臂骨骼。
- 待机低频轻瞥、慢眨眼、浅笑；首次安静约 8.5 秒后出现，后续留有停顿。倾听、思考、说话、触摸、隐藏、低动态与休息会取消微表演，不补播错过的动作。
- 首次摸头保持开心侧倾，冷却后的第二次独立摸头以温柔轻摆回应。同句去重、真实时间生命周期和口型优先保持。

## 验证

控制器定向 87 项回归通过，合并后的 15 个测试文件共 185/185 项通过；TypeScript、隔离 Vite 构建和差异检查通过。独立代码审查未发现阻塞问题。既有 3D CompanionScene 分块大小提示仍存在。

Chrome 在 412×960 和 1280×900 验收：新神态与六类动作可辨识，结束后姿态通道归零，头颈和服装未见断裂或横向溢出。最终六类动作样本每 3.4 秒约 88–91 个不同渲染帧；此为桌面 Chrome 视口模拟，不替代 Android／Ubuntu 实机性能结果。

连续约 39.5 秒待机采样覆盖轻瞥、慢眨眼、浅笑，嘴型始终为零；慢眨眼进行中切至倾听后，microExpression 变为 none。WebGL 主动丢失后，DOM 困倦、低头和嘴型仍工作；减少动态效果时缩肩及身体动作均为零。

公网直接触摸确认两次独立回应为 happy + tilt、tender + sway。长按进入休息后连续 9.5 秒采样均为 sleep、无微表演、嘴型为零，随后轻触正常唤醒。所有临时浏览器模拟设置已清除，隔离预览已停止，测试登录已退出。没有发出聊天或 Agent 执行请求。
