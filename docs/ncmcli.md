# 小伴网易云官方 CLI 技能

技能名 `petpal-ncmcli`，Agent 工具名 `petpal_ncmcli`。API 模式的本地或远程 Codex 自动发现内置技能；host 模式也可通过同一动态工具调用。Web/安卓的任务在所选 Windows/Ubuntu 电脑执行，音乐配置保存在那台电脑，不在手机上安装 CLI。

## 开始使用

1. 登录小伴，选择执行电脑。可以先说“检查网易云官方 CLI 的准备状态”。离线状态无需完整访问；准备文件和运行 CLI 都继承当前 Agent 的完整访问与审批设置。
2. 对小伴说“为这台电脑准备网易云官方 CLI”。小伴返回安装、配置、扫码的三个启动文件。Windows 双击 `.cmd`；Ubuntu 在终端执行 `.sh`。需要本机 Node.js 18+ 和 npm，文件仅准备就绪，不会自动安装或登录。
3. 没安装时先运行 `install`。它在当前小伴账号的私有目录安装固定 `@music163/ncm-cli@0.1.7`，使用 npm 官方源并禁用安装脚本。已全局安装此固定官方版本时也可复用其程序；仍使用小伴独立的账号配置。
4. 用户前往[网易云音乐开放平台](https://developer.music.163.com/st/developer/apply/account?type=INDIVIDUAL)，填写开发者资料、确认协议并取得 appId/privateKey。打开本机 `configure` 向导填写，再运行 `login`，用网易云音乐 App 扫码。私钥不用发给小伴或任何聊天。
5. 返回小伴说“检查网易云登录，然后搜索 xxx”。`login --check` 可能刷新登录 token；它属于实际 CLI 操作，按当前权限和审批执行。切换模型不改变这台电脑上该小伴账号的音乐配置。

向导使用外部 Node，避免 Windows 便携版每次解包的临时 Electron 路径失效。小伴移动数据目录或重新安装后，请重新准备向导。直接在普通终端运行 `ncm-cli configure/login` 使用的是普通终端的 HOME，不会配置小伴的私有账号。

## 当前能力

| 功能 | 本版入口 |
| --- | --- |
| 安装/配置状态 | 离线检查程序和凭据文件；不证明凭据有效或已经登录 |
| 搜索与歌单 | 官方 CLI 的 `search` / `playlist`；先查询真实命令帮助，使用本次意图概要 `--userInput` |
| Windows 桌面放歌/队列/歌词 | 现有网易云音乐 MCP，先检查该电脑实际能力 |
| Ubuntu 播控 | 已有兼容 MPRIS 媒体会话；不具备搜索选歌播放能力 |
| 定时推荐 | 小伴已有自动化，继承账号、执行电脑和权限 |
| 私钥、扫码、API 申请 | 用户在所选电脑操作 |

返回搜索结果或播放地址不等于已播放。官方 CLI 0.1.7 的 Windows mpv 播放管道共享，且有按进程名终止播放器的路径，所以当前工具不执行其原生播控。文件/图片封面上传、云盘、笔记、TUI、升级和诊断上报不在本版入口范围。

官方 CLI 依赖含已知漏洞的旧构建包及 image-size；它作为用户独立安装的可选运行时，未加入小伴主生产依赖。入口限制文件上传、参数覆盖、进程输出和时长，但不等同于操作系统沙箱。

## 维护与验收

技能改编自 [NetEase/skills](https://github.com/NetEase/skills) 固定修订 `58ff0771d6977feb847d6bfe322280eec4bec004`，保留原 Apache 2.0 许可和来源哈希。

本轮已验证真实 CLI 0.1.7 版本与未配置错误、账号隔离、取消/关闭、权限路由、生成向导的实际执行，以及真实 Codex 0.143 在私有 CODEX_HOME 下发现技能。真实 Codex → 小伴桌面工具 → 官方 CLI 的本机调用链与 Electron 39.8.10 的 Node 模式均通过；模型请求使用本机模拟服务。未取得真实 API 凭据，未宣称在线搜索、歌单修改或播放验收完成。后续客户端需重新打包才能获得新技能和工具；本轮只更新代码及本机服务。

本机服务更新时保留现有账号、模型和对话。旧 Agent 对话仍可查看；内置工具修订会使旧 Codex 线程失效，使用新技能时请新建 Agent 对话。不会在宿主 Codex 的全局技能目录安装此技能。
