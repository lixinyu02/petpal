# 自动化功能验收（0.9.9）

2026-10-05，独立账号自动化页面和中央/远程 Codex 工具。

## 已验证

- 最终冻结前完整串行回归2058/2058通过，无失败、取消或跳过；TypeScript与diff检查通过。
- 隔离 JsonStore：UUID 创建/运行去重、revision 竞争、账号/模型/电脑/权限隔离、DST、逾期跳过、先持久 claim 后派发、重启 unknown 暂停。
- 真实保存队列被阻塞时停止、断线或退出登录，尚未提交的创建/暂停/运行被 guard 拒绝，不能迟到落盘。
- 未知任务需用户明确核对电脑并确认停止，状态原子取消、计划保持暂停；失败不改 live，旧快照不能恢复 unknown。
- 同计划30次记录与安全生成会话保留，普通聊天配额独立；来源、其他账号、运行中和不确定结果不被误删。未绑定/删除计划后的保留结果可在普通历史查看和清理。
- 远程自动化写工具遵守本轮 ask/review/auto。中央验证完整参数和实际账号审批，绑定 callId/指纹，不接受客户端自报已批准。
- 实际 TSX 事件：保存、编辑、确认未知结果、重复点击、账号切换、未保存保护、只读结果和任务通知导航。页面内确认支持键盘和取消，不依赖 window.confirm。
- 真实 Codex/GPT-6.1 Sol：在隔离 profile 中调用新工具创建暂停的每日计划，范围从实际任务继承；另一个一次性计划按真实时钟与15秒调度 tick 自动完成“自动化验收成功”的回复。未提供桌面工具、未操作用户软件，未改生产数据。
- Chrome 验证新建暂停计划保存及未保存导航保护，实际412×960无横向溢出。插件在旧原生确认框处失去响应后，以内置浏览器完成新内联确认和实际412×960/320×320验证，两者 scrollWidth 等于视口宽度。
- 正式0.9.9包内前端另以Chrome完成内联草稿确认、继续编辑保留内容及暂停计划保存；412×960无横向溢出。移动视口checkbox的插件指针切换失败后，聚焦Space正常；整页截图工具超时，已保存视口截图。旧缓存页的原生确认阻断证据保留，未将工具受限路径写成全部通过。
- 正式上线后Chrome使用test账号核对自动化入口、新建表单五种时间选项、固定电脑/模型/目录/权限；取消空表单，没有创建生产计划或提交任务。412×960与320×320无横向溢出，短屏导航可滚动、设置与注销可达。登录门禁、退出账号和浏览器视口恢复通过。

原始证据位于本机 `evidence/automations-099/`，含 `live-agent.json`、测试日志、`ui-acceptance.json` 和截图。隔离模型与时钟测试不等同于实际目标电脑 GUI 操作；本次自动化真实模型验收只执行无桌面工具的固定回复。

正式构建及生产Chrome补验收见 `evidence/release-099-20261005/chrome-canonical-099.json`、`chrome-production-099.json`；生产后端升级、精确业务数据比对、清理退出/guardian恢复事件和四端发布边界详见 `acceptance-0.9.9.md`。

## 运行条件

服务器和固定执行电脑须运行。网页关闭或退出登录不取消已保存计划；电脑离线、忙碌、错过时间会记录跳过，不换电脑或补跑。停用账号、收回模型/Agent权限仍会阻止执行。执行器客户端需更新到0.9.9才能提供新自动化工具；旧客户端能力协商继续兼容。

每账号最多50项计划，每计划最近30次运行。创建/手动运行回执每账号最多500项，达到上限会拒绝新增并提示管理员整理；保留旧回执以避免已执行请求被重复派发。

四端包、生产上线及正式Release验收另见 `acceptance-0.9.9.md`，不以本文的隔离功能验收代替。
