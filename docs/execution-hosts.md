# 选择执行电脑

同账号电脑功能让 Web、Android、Windows 和 Ubuntu 共用一个人的账号、模型和聊天记录，再单独选择 Agent 在哪台电脑执行。Chat、图片和语音仍通过当前登录的个人服务处理。

## 让电脑上线

1. 使用 [v0.8.0](https://github.com/lixinyu02/petpal/releases/tag/v0.8.0) 或更高版本的 Windows / Ubuntu 客户端。旧 **v0.7.0** 包需要升级；仅刷新网页不能给旧桌面包增加执行器。安装包版本和验证范围以对应 Release 为准。
2. 在电脑客户端连接你的公共个人服务，例如 `https://magicdatou.top:44318`，登录要使用的账号。电脑和手机需要连接**同一服务、同一账号**。
3. 电脑会自动登记真实电脑名和平台。回到 Agent 的「执行电脑」列表，可以看到 Windows、Ubuntu / Linux、在线状态；当前桌面客户端对应的条目标为「此电脑」。没有看到时点击刷新，并检查电脑客户端登录状态。
4. 在手机网页、Android 或其他电脑登录同一账号，选择这台在线电脑，再选择模型和权限后发送任务。账号须由管理员开通 Agent；普通新账号不会因为登录桌面就自动获得完整访问。

不需要打开电脑入站端口，也不需要额外配对密码。桌面执行器主动连接中央个人服务。中央服务器作为执行位置继续保留，兼容已有会话。

## Chat + Agent 默认电脑

打开聊天工具栏的「Chat + Agent」，在「默认执行电脑」选择目标，点击「设为默认执行电脑」。保存成功后才能打开「自动派发 Agent 任务」。需要操作软件时，Chat 将任务交给这台电脑上的真实 Codex，结果随后回到原聊天；伙伴语音聊天使用同一默认电脑。

默认电脑保存在当前账号，同一服务的新版界面登录或刷新时会读取它。模型、项目目录和本次任务权限仍按各自设置执行；启用状态和自动运行权限不会跨登录保存。电脑离线时保留原默认并提示不可执行，不会转交另一台电脑。

2026-10-02 的默认保存入口已先更新网页与后端，旧安装包的内置界面需要下一次客户端更新才会包含该按钮。

## Windows 管理员确认

「完全访问」描述 Agent 的任务访问范围，执行器仍继承当前客户端的 Windows 系统身份。软件自身要求管理员权限时，系统可能弹出 UAC，需在执行电脑上确认，远程网页不能代替系统授权。

国服《无畏契约》的官方 launcher、WeGame 和 tcls_core 均声明 requireAdministrator；本机实测已拉起启动器，随后遇到 UAC，游戏主界面尚未验证。取消管理员提示或启动器退出都不能算游戏已启动。助手遇到权限提示应停止重试并说明当前阶段。

## 关闭窗口与退出

关闭桌面主窗口后，客户端留在托盘，继续在线并处理任务。注销、切换账号或个人服务，以及从托盘彻底退出，会停止这台电脑的执行器和当前任务。电脑关机、网络中断或程序异常退出后，在线状态在租约到期后消失。

手机关闭页面不会把任务迁移到别的电脑；重新打开同一会话可以继续查看中央保存的消息、审批和队列。运行中的电脑仍须保持客户端和网络可用。

## 切换与队列

「执行电脑」只选择任务目标，不会切换个人服务、重新登录或清空聊天。切换到另一台电脑时，新电脑使用新的 Codex 线程并接收有限近期文字上下文；原电脑文件不会自动复制过去。

发送时固定电脑、模型和权限。任务执行中、队列未清空或上次提交尚未确认时，界面锁定执行位置；追加指令、审批和停止仍发往原电脑。每个队列条目显示自己的电脑名。离线条目不能新提交，系统不会静默改用在线电脑或中央服务器。

如果提示「执行状态未知」，原任务可能仍在运行。先在原电脑退出小伴，并检查任务进程是否停止；不要立即重复同一指令。该队列会暂停，未知任务不会自动重跑。界面提供「开启新对话」处理其他任务，原会话和状态记录保留。

## 模型与数据

管理员继续在中央个人服务配置模型并向账号分配权限。执行器使用仅适用于当前电脑连接、任务和固定模型的短期 Responses relay 凭据，中央上游 API Key 不下发到桌面。任务完成、凭据过期或权限撤销后，该 relay 凭据失效。

桌面工作区和 Codex 数据按中央实例与账号隔离。Agent 图片只来自当前账号已上传并授权给本次任务的附件。工作区隔离不等于操作系统沙箱：选择完整访问时，实际允许的本机操作仍由账号权限、任务策略和平台限制决定。

多端同步来自同一中央个人服务。连接另一个服务实例属于另一套账号和历史，不会自动迁移数据。原 0.7.0 的平台验收不能替代新客户端在 Windows、Ubuntu 或 Android 上的实际验证。
