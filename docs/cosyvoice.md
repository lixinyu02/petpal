# CosyVoice 朗读

当前源码新增 CosyVoice 适配。已经发布的 v0.6.1 EXE 和 Web ZIP 保持不变，不包含此后新增的功能；部署时需要使用当前源码重新构建前端，并启动对应后端。

## 配置和使用

在「连接与设置 → 语音与设备」选择 CosyVoice。主机管理员配置 Gradio 服务的根地址、可选 Bearer API Key、参考音频对应的准确文本，并上传参考 WAV。参考声音须为至少 16 kHz 的非静音 PCM WAV，时长 1 至 30 秒，大小不超过 5 MiB；只使用自己有权使用的声音。

参考音频保存在个人服务的私有数据目录，不随源码分发。普通账号只能使用管理员配置的共享音色，不能修改服务地址、读取参考文本/文件或上游密钥。每个账号独立保存朗读引擎和语速；CosyVoice 语速为 0.5 至 2。保存配置只是准备连接，点击试听才会实际生成音频。

保存 CosyVoice 朗读引擎后，可在设置中试听或在聊天中朗读完整回复。自动朗读仍默认关闭。音频播放使用当前账号在当前设备选择的扬声器；浏览器不支持输出选择时使用系统默认输出。系统朗读依旧使用操作系统的默认扬声器。

角色口型按音频播放进度近似同步，不是音素级口型。停止、切换账号、页面隐藏和退出会取消本地合成请求、停止播放并释放音频。上游 Gradio 已开始的 GPU 任务可能仍会执行完，不能把客户端停止等同于强制终止远端 GPU 计算。

## 接口与访问边界

| 接口 | 用途 | 权限 |
| --- | --- | --- |
| `GET /api/voice/cosyvoice` | 读取可用状态，管理员可读取配置 | 已登录 |
| `PATCH /api/voice/cosyvoice` | 修改固定上游和参考文本 | 主机 owner |
| `POST /api/voice/cosyvoice/reference` | 上传原始 `audio/wav` | 主机 owner |
| `POST /api/voice/synthesize` | `{ "text": "你好" }`，返回音频字节 | 已登录且本账号已选择 CosyVoice |

服务内部对接 Gradio 5 的 upload、call、队列事件和音频下载；调用者不能指定任意服务地址、文件路径或下载 URL。后端限制请求文本、响应大小、并发、频率与超时，禁止上游重定向。未登录请求返回 401，账号退出/停用/撤权会中止仍在运行的本地请求。密钥和 Gradio 内部文件路径不会回传给客户端。

公网客户端应连接个人服务的 HTTPS 地址，复用小伴账号认证。路由器只需转发个人服务端口；不必把没有身份认证的 Gradio 界面、upload 或 file 接口直接公开。部署者仍须配置有效证书和精确来源名单。域名在局域网内访问成功仅证明 DNS/回流链路，不能替代独立外网测试。

## 当前验收范围

本次上游实例的预训练音色列表为空，先使用 Windows 系统合成的中文参考样例进行测试。首次实测的 upload 和任务创建成功，但队列返回 `event: error` / `data: null`，Gradio 自身页面也显示错误，未产生可验证的音频。具体运行状态和后续证据见 [接入任务](workflow/2026-09-28-petpal-cosyvoice-issues.md)。

CosyVoice 是语音合成服务，不提供 ASR。通用远程 TTS、浏览器识别及远程 ASR 的原有设置仍为预备配置，不会自动启用录音。
