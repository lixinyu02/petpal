# CosyVoice 朗读

当前源码新增 CosyVoice 适配。已经发布的 v0.6.1 EXE 和 Web ZIP 保持不变，不包含此后新增的功能；部署时需要使用当前源码重新构建前端，并启动对应后端。

## 配置和使用

在「连接与设置 → 语音与设备」选择 CosyVoice。主机管理员配置 Gradio 服务的根地址、可选 Bearer API Key、参考音频对应的准确文本，并上传参考 WAV。参考声音须为至少 16 kHz 的非静音 PCM WAV，时长 1 至 30 秒，大小不超过 5 MiB；只使用自己有权使用的声音。

参考音频保存在个人服务的私有数据目录，不随源码分发。普通账号只能使用管理员配置的共享音色，不能修改服务地址、读取参考文本/文件或上游密钥。每个账号独立保存朗读引擎和语速；CosyVoice 语速为 0.5 至 2。保存配置只是准备连接，点击试听才会实际生成音频。

保存 CosyVoice 朗读引擎后，可在设置中试听或在聊天中朗读完整回复。自动朗读仍默认关闭。音频播放使用当前账号在当前设备选择的扬声器；浏览器不支持输出选择时使用系统默认输出。系统朗读依旧使用操作系统的默认扬声器。

角色口型按音频播放进度近似同步，不是音素级口型。停止、切换账号、页面隐藏和退出会取消本地合成请求、停止播放并释放音频。上游 Gradio 已开始的 GPU 任务可能仍会执行完，不能把客户端停止等同于强制终止远端 GPU 计算。

## 接口与访问边界

| 接口 | 用途 | 权限 |
| --- | --- | --- |
| `GET /api/voice/cosyvoice` | 读取可用状态，管理员可读取配置 | 已登录 |
| `PATCH /api/voice/cosyvoice` | 修改固定上游和参考文本 | 主机 owner |
| `POST /api/voice/cosyvoice/reference` | 上传原始 `audio/wav` | 主机 owner |
| `POST /api/voice/synthesize` | `{ "text": "你好" }`，返回音频字节 | 已登录且本账号已选择 CosyVoice |

服务内部对接 Gradio 5 的 upload、call、队列事件和音频下载；调用者不能指定任意服务地址、文件路径或下载 URL。后端限制请求文本、响应大小、并发、频率与超时，禁止上游重定向。未登录请求返回 401，账号退出/停用/撤权会中止仍在运行的本地请求。密钥和 Gradio 内部文件路径不会回传给客户端。

公网客户端复用小伴账号认证，路由器只需转发个人服务端口，不必公开没有身份认证的 Gradio 界面、upload 或 file 接口。当前部署按用户选择使用 HTTP，来源名单仍保持精确匹配；HTTP 不提供传输加密。域名在局域网内访问成功仅证明 DNS/回流链路，不能替代独立外网测试。

## 当前验收范围

2026-09-29 已完成真实合成验收。用户修复上游后，又修正了小伴与 Gradio 5.4.0 简化 call API 的会话绑定及错误 `/gradio_a` 元数据前缀；实际下载始终使用固定服务地址和校验后的音频路径。通过现有 HTTP 域名的认证路由返回 200，约 7.1 秒生成 9.84 秒、24 kHz / 16-bit / mono 的有效非静音 WAV。主账号已保存 CosyVoice 引擎，其他账号设置保持原样。

Chrome 使用相同前端与修复后的后端，在隔离账号数据实例中连接真实 CosyVoice，验证了合成、进入播放、停止和自然结束；不是 fixture 音频，也没有人工确认物理喇叭或中文发音质量。初次链路测试使用 Windows 系统合成参考音，用户随后反馈电子感较重。当前部署已换为 CosyVoice 官方仓库的 `asset/zero_shot_prompt.wav` 示例（对应文字“希望你以后能够做的比我还好呦。”），仅从 Float32 转为 PCM16，保持采样率和时长。官方示例不随小伴源码或安装包分发，后续可在设置中更换。新提供的 50001 端口仅是只读日志查看器，合成地址继续使用 50000。具体证据见 [接入任务](workflow/2026-09-28-petpal-cosyvoice-issues.md)。现有公网入口此前已由独立外部节点确认可达，本次匿名合成仍返回 401。

CosyVoice 是语音合成服务，不提供 ASR。通用远程 TTS、浏览器识别及远程 ASR 的原有设置仍为预备配置，不会自动启用录音。

## 音色与引擎排查

CosyVoice 的 3s 极速复刻会模仿参考声音；系统 TTS 参考可能保留电子感，链路成功不代表自然度已经验收。2026-09-29 更换官方示例后，同文案通过固定上游适配和生产域名分别生成的 WAV 完全一致（7.36 秒 / 24 kHz / 16-bit / mono），小伴没有变调、变速播放、压缩或回退处理；实际听感由用户试听确认。

未登录访客和新成员账号默认使用系统朗读。使用 CosyVoice 时先登录，在语音与设备中选择并保存该引擎；CosyVoice 失败会明确报错，不会自动换成系统语音。HTTP 与 HTTPS 属于不同站点，迁移后须重新登录。
