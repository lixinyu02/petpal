# 0.7.0 工作台验收

本版统一登录后的 Chat / Agent 入口，加入执行主机选择、模型搜索、任务权限、追加引导、持久队列、图片附件和公开客户端目录。Android/Web 使用远程 Agent；Windows/Ubuntu 也可在内置个人服务运行 Codex 0.143.0 与 OpenCLI 1.8.8。

## 功能与权限

- 登录身份验证通过前不挂载聊天、语音、设备与任务界面。管理员给账号分配模型和 Agent 授权；新成员默认只有 Chat。原有数据保留，授权不会隐式提升。
- Agent 的只读、工作区、完全访问与需要时询问、自动审查、自动运行映射到实际 CLI。每次任务冻结模型与权限；更改草稿不会升级已排队任务。
- 当前任务支持追加引导；最多排队 5 条，可编辑、删除和恢复。停止任务会暂停队列，重启不会自动重放。丢失响应后的确认重试沿用原提交 ID、地址和内容。
- PNG/JPEG/WebP 每张最多 8 MiB，每条最多 4 张，按用户隔离。Chat 使用实际多模态协议；Agent 引用服务器控制的本地附件。仅文字模型明确禁用图片。校验覆盖格式结构、尺寸和容器，不声称完整像素解码审查。
- 二次元角色优先显示基础纹理，移动端减轻 WebGL 负担；渲染失败或上下文丢失时保留同角色的轻量动画与重试。
- 登录后的下载目录读取固定 GitHub 仓库的实际发布资产。GitHub 公共安装包本身保持公开。

## 自动化与浏览器

全量 Node 测试 **403/403** 通过，TypeScript 与 Vite 构建通过。测试覆盖账号撤权/退出、队列与引导竞态、真实 CLI 权限映射、附件归属与多模态序列化、桌面远程传输及凭据隔离、下载清单和公开源码边界。

Chrome 实际验证了登录/退出、模型搜索与键盘选择、纯图片 Chat、运行中追加引导、排队编辑/停止/恢复，以及运行中进入下载后返回任务。注入提交响应丢失后，两次请求保持同一个地址、内容和 UUID；验收后已恢复正常网络行为。

实际 CSS 视口 412 × 915 下页面无横向溢出，二次元 WebGL 可见。主动模拟 WebGL context loss 后，同角色 DOM 动画继续，点击重试恢复 WebGL。这是 Chrome 响应式验证，不能替代手机真机测试。

## 线上验证

服务升级保留实例、账号、模型、原会话及消息。用户明确授权的测试账号已取得完整 Agent 授权；生产默认任务策略仍为只读、需要时询问。

真实 GPT-6 Luna Responses 文本与单图请求成功，真实 Codex 只读任务创建 thread/turn 并正常完成。公开 HTTPS 与本机指向同一服务；语音、图片、下载和任务的匿名请求均返回 401。原有测试账号 3 个会话逐项哈希一致，另外保留 2 个明确标注的验收会话。

- Web：ZIP 根目录直接包含 `index.html`、版本和资源；23 项文件与最终 dist 逐字节一致，公开 HTTPS 上的全部 23 项也逐字节匹配。
- Windows：最终便携 EXE 的 1,969 项文件字节检查通过；127 项冻结输入未变。在全新配置与受限 PATH 下实际启动最终 EXE，登录门禁、明确的本机管理员登录、内置 Codex/OpenCLI、双角色双窗口渲染与切换、透明桌宠角和退出清理通过。首轮 portable 检查只产生登录截图后 exit 1，未取得具体原因；同一字节的提取 payload 与最终 portable 随后均完整通过，保留失败记录而未修改应用。没有商业代码签名。

Windows 程序没有商业代码签名；Android 是供试用的开发签名 APK。通用远程 ASR/TTS 的配置入口不等同于已经实现所有供应商适配；当前远程语音朗读使用已接入的 CosyVoice，口型按播放进度近似同步。
