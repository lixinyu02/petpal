# Agent 项目目录

Agent 可以在你指定的现有项目文件夹中运行，Chat + Agent 派发的后台任务也使用这个设置。

1. 登录后选择 Agent 模式，先选择执行电脑。
2. 展开模型和电脑下方的“项目目录”。输入**所选执行电脑上的绝对路径**，例如 Windows 的 `C:\Projects\demo` 或 Ubuntu 的 `/home/me/projects/demo`。
3. 点击“使用此目录”，再发送任务。任务详情和队列会显示提交时选定的目录。

Chat 模式中打开“Chat + Agent”设置，可以配置同样的项目目录。手机或网页提交远程任务时，路径属于执行电脑，而非手机或浏览器所在设备。

“恢复默认”会使用执行电脑原有的默认工作区。目录偏好按服务、账号和执行电脑分别保存；切换电脑后请核对路径。同项目可以续接原生 Codex 线程，切换项目或电脑会新建原生线程并保留近期文字上下文。

目录必须已经存在并且可访问。执行端会检查真实路径，不会自动创建文件夹或在失败时改用默认目录。工作区权限账号只能选择默认工作区内的真实子目录；拥有完整 Agent 授权的账号可以选择外部项目，本轮读写能力仍由访问权限设置决定。

执行、排队、状态未知或等待提交确认期间，目录固定为任务快照。运行中的追加指令沿用该目录；需要换项目时，等当前任务完成且队列清空后再修改。

网页和中央后端已支持此功能，Windows/Ubuntu 0.9.6 安装包包含对应桌面执行端。旧执行端会明确提示升级，默认工作区继续兼容。当前不提供文件夹选择器或远程目录浏览。
