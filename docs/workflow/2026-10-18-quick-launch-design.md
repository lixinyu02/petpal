# 快捷入口与定时任务

- Date: 2026-10-18
- Complexity: L2
- Status: implementation

## Goal

用户希望一键查询天气等常用任务，也能定时执行。提供登录后的“快捷入口”页；用户配置一次指令、模型和执行电脑，以后点一次即可运行并查看结果，定时使用现有每日/工作日/每周/间隔/一次性计划。

## Design

快捷任务复用现有自动化记录和持久运行授权，不另建调度器。新增可选quickLaunch布尔标记，旧记录默认为false且不自动迁移文件；普通自动化可加入/移出快捷入口。快捷任务默认关闭定时，仍可手动执行；显式开启定时后才进入调度。创建/修改沿用账号隔离、电脑/模型权限、幂等requestId、revision和未知结果确认。旧无标记请求的幂等指纹保持兼容。失败/断线不自动重复派发，运行记录和结果对话沿用原机制。

模板提供查天气、打开音乐及自定义指令。天气预填此前用户使用的上海浦东新区北蔡镇，要求内置OpenCLI使用真实官方天气数据、注明时间和来源、缺数据坦诚说明；地点可编辑。模板只是编辑草稿，不自动创建计划或执行软件。执行电脑和模型必须是当前账号实际可用对象，不为普通账号选择中央服务器。

App增加按需加载的shortcuts视图，地址`/?chat=1&shortcuts=1`，入口在工作台导航与伙伴首页。复用AutomationsView，shortcuts模式显示快捷任务与模板；每项主按钮一键运行，提供定时/编辑及结果入口。正常自动化页保持管理全部记录与既有操作，编辑器可标记快捷入口。导航沿用未保存草稿和任务进行中的保护。立即运行和后台调度均要求目标电脑在线，不谎称离线完成。

## Visual / Interaction

- Visual thesis: 延续淡白背景与现有单一强调色，以紧凑、清晰的任务按钮为主。
- Content plan: 页面标题和添加入口；少量可配置模板；已保存的快捷任务及状态；按需打开编辑器与运行记录。
- Interaction thesis: 卡片轻微hover反馈、编辑器/详情短过渡，全部遵循reduced-motion；412×960单列、足够触控面积，导航不遮挡输入。

## Compatibility / Non-goals

保留手动启用代理、全部既有账号/权限/模型、聊天草稿和客户端下载。只发布Web/后端及源代码；客户端使用共用源码，但本轮不自动重打安装包。Web和安卓的远程执行继续复用已登录电脑，不新增手机本机CLI或无凭据执行。

## Verification / Rollout

Schema与持久化测试旧记录、幂等、隔离、非法标记和不启用定时的手动运行；UI实际事件测试模板、保存、立即运行、工作日等计划、重复点击/网络不确定、账号切换和编辑离开保护；App导航按需加载回归。TS/Vite，Chrome桌面及412×960浏览器验收，实际天气查询与调度/派发路径验收并区分真实服务与合成模型。上线前固定旧源码回退、私有备份和fresh idle，之后校验业务、代理规则、正式下载、升级指针及服务健康。真实任务测试只创建可识别的验收任务，不启用持续定时，不删除用户数据。

## Implementation findings

实际中国天气网乡镇预报在小时与三小时范围的逐日分组交界出现13小时缺口。仅允许日期分组已验证、严格递增且不超过24小时的交界稀疏跨度，组内仍限制不超过3小时。返回coverage/coverage_gaps并提示缺口，不插值、不伪造发布时间；重复、倒序、日期错组及过大缺口继续拒绝。天气模板要求说明缺口。
