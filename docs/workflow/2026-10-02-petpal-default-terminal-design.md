# Chat + Agent 默认执行电脑与软件启动

- Date: 2026-10-02
- Complexity: L1
- Status: in_progress

## 目标与方案

用户希望在 Chat + Agent 下让助手打开电脑软件，并实测国服无畏契约。沿用既有 Chat run_agent → 所选电脑 Codex → Computer Use / 系统操作链路；不另建游戏专属命令，也不把启动器出现当游戏已经运行。

将默认执行电脑保存为账号的 chatAssistantHostId，服务端只接受 central 或属于当前账号的执行电脑。默认电脑跨 Web、Android、PC 同账号读取；不保存开启状态、权限或自动运行授权。界面明确提示默认执行电脑，保存成功后才允许启用；默认电脑离线时保留原选择，不自动转派。模型和项目目录延续现有偏好与权限校验。启用但没有电脑时必须报错，不能静默退化为普通 Chat。

旧浏览器偏好只作为未设账号默认时的候选，需显式保存；已有账号默认优先。每轮派发仍冻结电脑、模型和权限，设置变化只影响后续任务。

## 验证与上线

验证账号隔离、归属、离线保存、清空和重启持久化，偏好优先级与 snapshot；真实 Chrome 的普通账号弹窗、保存和 412×960；真实 Chat 派发 Codex 打开国服无畏契约，核对工具执行、实际目标进程或窗口。若出现登录/UAC/更新等系统交互，如实记录所在阶段。上线前检查无活动任务，备份源码与私有状态，保留冻结客户端和更新清单。
