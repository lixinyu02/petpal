# Cubism 手部与情绪动作增强

- Date: 2026-10-02
- Complexity: L2
- Status: done

## 目标和边界

在 V7 原画和已验收头脸／刘海比例上补充真实 Cubism 手部几何绑定，动作通过原生 motion 曲线执行，继续在网页先体验。原画双手交握、衣袖与身体烘焙于同一层，因此本轮实现成对双手轻抬、轻摆和衣袖跟随，不声称已能独立动手指或大幅抬臂挥手。

新增 V8 独立目录，保留所有旧资产。沿用 V7 PSD／表情贴片并细化身体网格，增加 ParamHandsLift、ParamHandsSway、ParamSleeveEase 三个真实参数。手指和双手接触区采用相同平移，衣袖向固定颈肩平滑过渡；任何组合不得拉扯脸、头发、领口，不能出现翻面或破洞。原默认中性保持。

## 动作及运行逻辑

在待机、轻触和打招呼基础上新增开心轻摆、害羞轻收双手、礼貌点头等短动作。手势曲线有起落和停顿，回到中性；不在每个语音分片重复起动作，不堆叠同一关节。运行桥只绑定真实存在的参数，旧模型保持兼容。隐藏、休息、减少动态和停止语音取消相关动作，手动互动与语音来源区分。

## 实施和验证

一个 issue 内分别完成作者绑定、运行时与曲线、原生测试及 Chrome 整合。先用官方 Core 验证真实参数响应、头脸不动、双手接触与位移／网格边界，再在 Chrome 并排看中性及连续动作，验收桌面、412×960、点击、停止、低动态。相关回归、TypeScript、生产构建通过后，仅静态网页部署，账号、后台 Agent、下载包、更新清单保持。记录资产来源、原始导出和后处理哈希，公开审计后提交推送。

官方 Editor roundtrip、独立指骨／手势拓扑、新遮挡底图、大幅抬臂和客户端重打不包含在本轮结果中。

完成结果见 [V8 验收](../cubism/hand-gestures-validation.md)。实际 Core 的双手共同位移残差为 0.1996 个源像素，以 0.25 px 门限验证，不声称父变形器插值后的顶点位移逐位相同。
