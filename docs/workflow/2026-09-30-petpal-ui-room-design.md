# 聊天与伙伴界面减负

- Date: 2026-09-30
- Complexity: L1
- Status: implemented and verified

## Background

Chat + Agent 配置在页面中展开，会把聊天、人物和语音字幕挤向下方。桌面 Chat 的模式、整行模型和协作入口分占三行，语音页又重复展示说明文字。

## Goal

减少常驻控件、重复说明和纵向占用。保持 Chat / Agent、模型、执行电脑、权限与语音功能可发现、可操作。

## Solution

协作入口改为轻量按钮，详细设置在独立浮层中显示，手机使用可滚动的底部面板，不挤压工作区。桌面 Chat 的模式和模型收为同一工具行；手机保留两行清楚的入口。Agent 的模型与电脑在手机并列。语音页将聊天模型与协作入口组成轻量设置行，字幕和主操作优先，减少重复文字。保留明确的状态和错误提示。

## Impact

仅修改 React 视图和样式，沿用既有模型、主机、权限、语音与后台任务接口；网页先上线。

## Risks

浮层需处理 Escape、焦点、遮罩、嵌套模型/权限选择以及短屏和软键盘；展开配置时不得隐式改变权限或开始任务。

## Verification Plan

Chrome 对比桌面与 412×960 的 Chat、Agent、伙伴语音页，验收模型选择与设置浮层开关、键盘返回、无横向溢出；TypeScript/Vite 构建；静态 diff 和公开源码审计。部署仅替换网页静态资源，保留生产配置与历史。

## Verification Result

Chrome 已验收 1280×900、412×960、844×390 和 412×300。手机 Chat 工具区从 178px 降到 115px，聊天可用高度从 504.31px 增加到 586.51px；设置浮层打开前后布局保持。修复了 closed details 中隐藏 select 被误列入焦点序列的问题。完整记录见 `2026-09-30-petpal-ui-room-validation.md`。

## Visual thesis

延续奶油白与浅绿，以人物、消息和留白为主，设置降为安静的工具入口。

## Content plan

工具行负责模式与当前模型；独立面板负责执行设置；语音工作区只保留当前状态、字幕与主要操作。

## Interaction thesis

面板短促淡入，手机从底部滑入；触发器呈现开启状态；保留角色已有动作，并尊重减少动态效果偏好。
