# 所有账号共享服务器代理配置

- Date: 2026-10-17
- Complexity: L1
- Status: validated implementation

## Background / Goal

用户手机显示暂无代理配置，因为已托管的配置只分配给owner。用户明确要求这份配置默认分给所有人。本轮让所有现有及以后新增的可用账号均能读取该配置，客户端仍由用户选择导入和启用。

## Solution

现有配置新增可选allUsers布尔授权。旧10字段存储兼容，旧配置默认false；只有管理员能修改。allUsers为true时，按当前用户表动态判断有效且未停用账号，不需要在创建用户时复制授权。已有userIds显式分配保留，其他配置及默认私有语义不变。管理员元数据和编辑页显示“所有账号（包括以后新增）”，普通元数据不暴露账号列表。

API接口和Android元数据字段保持兼容，不改变原YAML、摘要、日本IEPL优先级或故障转移规则。匿名/停用账号禁止读取。此次先用旧API给全部现有可用用户授权，然后部署兼容后端和Web，最后把目标配置切换为动态allUsers。仅后台和Web需要更新，无需重打客户端。

## Validation / Rollout

仓库单测覆盖旧存储、显式授权、不认识/停用用户、动态新增、撤销allUsers、布尔类型、重启和原子权限重验；HTTP验证管理员写入、普通账号只读、匿名401及动态新账号；UI验证开关和原有选择保留。定向测试、TS/Vite、自审通过后，在生产fresh idle时备份并更新服务，验证账号/业务数据及配置YAML摘要保持、认证下载可用、匿名拒绝、服务健康。源码和无凭据文档提交Git；真实订阅和用户数据只保留私有目录。

## Boundaries

仅这份用户指定的托管配置设置allUsers；不将其他私有配置默认公开，不修改系统代理，不代用户启用手机代理。新账号指当前服务内的有效账号，匿名或其他服务账号不获访问。
