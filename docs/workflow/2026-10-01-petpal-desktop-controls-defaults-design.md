# 电脑与音乐控制默认启用

- Date: 2026-10-01
- Complexity: L1
- Baseline: f63ec5c

用户要求电脑控制、网易云和 QQ 音乐默认启用。目前固定工具入口已注册，实际调用会连接 MCP，但新建配置的 enabled 为 false，导致首次请求无法连接。

新电脑配置在已支持的平台/架构默认开启 Computer Use，profile 仍为 full。音乐配置按现有平台支持判定，Windows 默认开启网易云与 QQ，Linux 默认开启 QQ，网易云保留系统 MPRIS 媒体控制。既有持久化配置（包括关闭、profile、路径、revision）原样保留，避免反复覆盖用户选择；本次用户要求也用于明确启用当前已部署主机的对应配置。

配置及状态读取只读本机设置/静态就绪，不启动 MCP 子进程、不安装依赖或打开应用。实际 Agent 调用仍经账号完整访问授权、所选执行电脑和现有任务审批；不提高成员权限或默认任务访问级别。音乐 Python 依赖缺失时报告现有准备入口，QQ 返回链接保持原有能力边界。

界面区分已启用与已连接，显示按任务连接及可关闭的说明。验证覆盖新配置、旧关闭配置和重启、平台fallback、只读无spawn、lazy连接、认证/审批/账号隔离，完成生产构建与当前部署状态回读。检查发现原有PC包缺少音乐和Computer Use桥，故同步交付0.9.4 Windows/Ubuntu新包，保留原包；Android仍为0.9.3，不重打。
