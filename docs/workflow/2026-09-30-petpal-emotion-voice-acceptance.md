# 二次元表情与朗读联动验收

日期：2026-09-30。范围：issue-39；仅更新网页和公共源码，未制作 Android、Windows 或 Ubuntu 安装包。

## 实现与自审

同一奶油白／浅橘人物新增伤心、难过、兴奋，加强开心和害羞。局部贴图与连续的眼眉、红晕、泪光、视线及姿态通道共用一套表演控制器，WebGL 与 DOM 采用同一表情映射。TTS 发音层最后合成，避免被表情闭口覆盖；第七张 sad 图片缺失不会使整个角色消失。

自审修复了两处表现问题：同句逗号后的普通分句继承之前情绪，明确否定或中性转折才清除；难过的 sad/downcast 两个通道合成后强度降低，使其明显弱于伤心。新增实际控制器到渲染器的组合测试，避免只测孤立通道而遗漏叠加强度。

文本匹配是保守的规则表演，不是心理识别。朗读进度是字符级估计，实际 PCM 能量增强口型和动作，不声称音素级同步。当前 CosyVoice 流式接口没有声明情绪控制字段，本轮不修改其音色或参考音频，也不声称声音已经随情绪换语气。协议说明见 [`../cosyvoice-emotion-capability.md`](../cosyvoice-emotion-capability.md)。
