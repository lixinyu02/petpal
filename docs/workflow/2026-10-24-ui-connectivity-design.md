# UI 与连接性排查修复

- Date: 2026-10-24
- Complexity: L2
- Status: scoped for implementation
- Baseline: `2ed61c4`，main 工作区干净

## Background

用户要求继续排查 UI 与可能的连接问题。上轮性能优化已上线，本轮应保留其产品输入与既有风格，只修复有可复现证据的布局、状态与网络恢复缺陷。

## Goal

检查桌面及360/412窄屏的登录、Chat、模型/连接设置；区分后端连通、登录有效、模型推理及语音服务能力。复现运行期掉线/恢复与上游失败，确保状态提示准确、用户输入与登录凭据保留、操作能够恢复。

## Non-goals

不重设计视觉、不扩展账号权限、不修改真实模型/代理/路由配置、不替换正式客户端或版本号，不向生产写入测试会话。用户未要求新goal，本轮不创建goal。

## Solution

1. 同一当前源码建立独立loopback fixture，合成账号和模型、关闭真实Agent/语音/自动化；Chrome截图与实际UI操作覆盖成功和失败路径。另低负载读取真实端点当前健康，输出脱敏证据。
2. 根据复现选择最小修改：请求生命周期/重试/状态展示及窄屏控件。保持session epoch、401核验、不可变消息、语音与权限边界；不给有副作用的请求自动重发。
3. 定向回归、TypeScript/隔离生产构建，Chrome同路径复验。需要上线时使用本轮新部署门禁、当前进程身份和保全清单，先资源后HTML；没有后端产品修改不重启服务。

## Impact

确认范围：api.ts成功响应正文解析/明确状态读取截止时间；App.tsx远程hosts结构检查、Agent轮询错误独立恢复、模型保存提交与列表刷新分离及保存中的表单互锁；LoginGate连接dialog可访问名称。ASR成功提示区分协议探测与真实录音。当前真实五模型/ASR/TTS探测通过，不能把这些前端缺陷归为当前上游失联。360宽度已确认默认模型select实际宽376、父容器315，右侧箭头被裁切；样式原错误地位于AccountsSettings懒加载CSS，移动至App所属model-settings.css并补minmax(0,1fr)/44px触控高度。Chrome插件导航与视口连用超时；IAB同源直接加载并分步调整视口已恢复实测，不归为产品渲染循环。

## Risks

网络超时不能当作登录失效；上游模型错误不能错误显示为后端离线；重连不得重复提交消息、权限批准或任务。手机断点调整不能裁掉选择项或阻断键盘操作。生产健康检查只证明采样时状态，不能当成长稳或全部模型可用。

## Verification Plan

先截图再修复；保留本轮前后UI和故障注入记录。定向测试真实迟到/取消/超时、scope切换与恢复。Chrome检查360×800、412×960和桌面，核焦点/滚动/错误恢复及无横向页面溢出。真实上游只做脱敏health/models及必要最小合成推理，不保存到业务会话；未测真机/语音硬件明确记录。每issue自审提交，最终推送并保留报告。
