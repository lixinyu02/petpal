# Ubuntu 自启与全屏

- Date: 2026-10-12
- Complexity: L1
- Status: final

## Background

桌面客户端已有 XDG 开机启动项与托盘偏好，但未提供全屏启动与明确的全屏退出入口。

## Goal

Ubuntu 登录系统后可自动启动小伴，并按本机偏好铺满当前显示器。允许普通窗口与全屏切换，保留退出与任务连接。

## Non-goals

不替换系统桌面、启用 kiosk 锁定、改系统显示参数或重启设备；只生成本地 Ubuntu 预览包，不发布新正式版本。

## Solution

延续已有 XDG 自启及账号验证。新增 startFullscreen 布尔偏好（默认关闭），旧文件兼容；启动最小化优先，首次从托盘显示时应用全屏。单独提供即时全屏切换，不写入启动偏好。F11 切换、Esc 退出，托盘提供退出全屏。状态以 Electron 窗口读取为准，窗口事件通知设置页，旧客户端保留原五项功能并隐藏不支持的入口。

Linux 自启只保留当前已知、安全枚举的 X11／Wayland 与 GL／ANGLE 参数，不复制任意命令行。ARM Mali 的现有三项参数因而可在登录自启时保留。

## Impact

desktop preferences、IPC/preload、主窗口生命周期、客户端设置和相关回归。全屏复用现有 412×960 自适应页面。

本地打包发现网页的 `dist/downloads` 安装包缓存被递归复制，导致安全审计拒绝 Windows 二进制。客户端 snapshot 现在只排除这个分发缓存，保留网页缓存及下载后端；归档审计和 current-dist 比较使用同一规则，其余安全拒绝规则保持。

## Risks

Linux 窗口管理器的异步全屏转换、隐藏启动抢焦点、失去退出入口、移动便携包导致旧自启路径、ARM Mali 启动参数丢失。使用事件与有界等待、首次显示策略、快捷键及实机核查处理。

## Verification Plan

偏好旧文件／持久化、自启回滚与路径、IPC 登录隔离、窗口重复实例／全屏进退、UI 旧桥兼容测试与 build。Ubuntu 当前桌面只读核查后独立验收，不触碰 LCD 固件和诊断状态。记录实际 native 结果与未测范围。
