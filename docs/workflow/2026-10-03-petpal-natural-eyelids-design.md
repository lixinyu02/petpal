# V12 原生眼睑闭合形状

复杂度：L2。问题跨原画分层、原生网格拓扑、MOC/CMO 导出、Core 裁剪和浏览器逐帧观感，不能以点击节奏测试代替形状验收。

## 当前问题

V11 用仿射平移保留睁眼上睫毛的拱形，而眼白收缩至直线；半闭时两者轮廓不能贴合，完全闭合仍像笑眯眼。眼白、虹膜和下睫毛在 EyeOpen 0–0.25 共同淡出，最后一段不是明确的眼睑遮挡。既有 TapHead 眼参数叠乘修复仅处理节奏。

## 本次范围

- 复用 V11 PSD 和原纹理，不生成或改画颜色；保持脸型、眉毛、头发、头身、手部、嘴部和 22 参数契约。
- 仅修订每眼眼白与上下睫毛的局部网格与闭合关键点。共享 X 列网格允许稳定的局部曲线变形；保留中性 UV/坐标映射。
- 闭合目标为眼角稳定的柔缓下弧，上睑主要下降、下睑少量上提；眼白使用同一边界。虹膜保持刚性，只由原生 mask 裁剪。取消最后四分之一的透明淡出，完全闭合仅隐藏亚像素残余。
- 先生成隔离 V12 候选，经真实 Core 与 Chrome 视觉验收后提升到全新的 V12 目录并切换网页默认。保留 V11 URL 与冻结 0.9.7 安装包。

## 验证

先用官方 Core 验证真实参数、mask、100 个中间闭合姿态的有限性/三角形方向、独立左右眼、虹膜刚性、无关网格一致性以及纹理哈希。再由主线程 Chrome 在原画/移动端尺度逐帧验收 1/.75/.5/.25/0 与自然眨眼、单眼 Wink。验收不通过继续调整候选，不宣称上线；CMO3 尚未经过官方 Editor 重导出。
