# 原创 Live2D 角色动效迭代

- Date: 2026-10-02
- Complexity: L2
- Status: done

## 目标与范围

延续现有奶油白、浅橘原创 Akari 的真实 Cubism 模型，不另换人物。以现有 20 个真实参数为边界，改善 Idle、点头、摇头的节奏，新增独立 TapHead / Greet 动作；修正 runtime 动作衔接、表情参数覆盖和说话口型，以更细腻的目光、眉眼、发梢和轻微身体姿态回应鼠标及触控。

## 用户截图后的范围修正

用户明确指出脖子、领口和人形变形。只读对照确认旧 neck / topwear 两层各自绘制锁骨和胸口皮肤，静态组合已存在硬直横线；头部 Z 绕嘴线旋转、颈部挂身体会进一步放大脱节。暂停发布动作候选，先修原创源层再重编模型。范围升级为 L2：一张连续颈肩 / 服装 / 双手素材替代两个冲突层，保留原脸部与头发身份；新的 continuous-body authoring profile 收小 XY / body / Z 关键形，classic profile 仍可重建旧版。

新素材、PSD、MOC 与图集放 v2，保留旧版不覆盖。动作 overlay 的 hash 合同须随新源模型更新。验收必须包含中性画面、组合头姿、互动、眉眼 / 口型及窄屏真实截图；有限值、参数范围和结构一致性只证明执行合法，不能证明视觉合格。若新的连续层或姿态仍不自然，继续修候选，不将未经视觉确认的模型上线。

不冒充尚未绑定的手臂或高精度音素动作。口型继续使用实际朗读进度、音频能量和文字节奏，不将其说成声学音素识别。隐藏、休息、减少动态、停止朗读必须保留安全状态；只维护当前同源 Core / Framework / shader 许可与 CSP。

## 实施与验证

一个 issue 内并行模型动作资产、runtime 子组件，根代理负责整合、场景和视觉验收。先冻结基线资源与网页截图，检查真实 Core 的姿态和动作参数；之后执行相关回归、TS、隔离 Vite 构建、实际浏览器表情 / 触摸 / 口型 / 生命周期 / 412×960 检查。网页验收通过后按既有授权上线网页和静态资源，保留旧资源、账号数据、下载包和升级清单；不因模型静态更新重启后台 Agent 或重打客户端。

静态资源使用新目录或版本引用隔离模型变更，先复制并核对，再原子更新 index。新动作资产的来源、哈希与验收范围独立记录，不将现有 PSD2Live 原始导出来源摘要当成后续手工动作资产的哈希声明。

## 交付结果

连续身体源图、20 层 PSD、独立 continuous-body profile 和新 MOC／图集完成；经典模型保留。111 项相关回归、TypeScript、隔离构建和官方 Core 35 姿态检查通过；Chrome 预览完成表情、模拟口型、交互与生命周期验收，静态／说话画面未见旧领口拼接。已原子上线网页，44 个公网资源 hash 匹配；Chrome 公网登录与 412×960 真实首页检查通过，backend、数据、下载和升级清单保持。详见 `docs/cubism/validation.md`。

官方 Editor 再导出、客户端重打与实体设备未包含在此次验收；本轮口型预览不是 ASR／TTS 上游重测。
