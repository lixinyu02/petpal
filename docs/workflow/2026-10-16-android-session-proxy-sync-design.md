# Android 续登与服务器代理配置同步

- Date: 2026-10-16
- Complexity: L2
- Status: final

## Background

Android 小伴主登录目前仅写 sessionStorage，关闭 WebView 后丢失；服务器会话实际持久化且有效期七天。代理只有匿名 HTTPS 订阅/本地导入，没有服务器托管目录或账号分配，Selector 选择只写运行中内核，重启丢失。

## Goal

关闭并重新启动安卓后恢复仍有效的小伴登录；服务器管理员可导入 Clash 文件、设置默认模式/组选择并分配账号，手机列出有权使用的配置、下载、更新并持久保存选择。完整验证身份隔离、失败保留、重启恢复。

## Non-goals

后续范围变更：用户在开发候选完成后明确要求“发布到正式链接去”，新增正式 Android/Web 0.9.13（code25）准备及发布 issues；桌面保留已验收的 0.9.12，签名更新保留其原始 URL 和摘要，不把旧包重命名。以下原开发阶段“不自动提升正式版”的边界已由这次明确授权覆盖。

不保存密码、不延长服务器会话、不绕过 401；不启用 VPN、不改变其他应用网络；不自动读取或分发现有主机的私有配置；本轮以 Android 消费服务器配置，Web 提供管理入口。正式版、GitHub资产和升级清单不自动提升；交付开发测试 APK。

## Solution

1. 独立 PetLoginSession 原生插件，Keystore AES-GCM、noBackup AtomicFile 保存当前服务地址/会话凭据种类/token；只允许可信本地主页面。登录成功等待写入，恢复仍走现有身份验证；当前会话401/主动退出清除，网络和服务故障保留。串行写入与代际检查防迟到恢复、旧登录写入复活。Web/桌面仍沿用原有策略。
2. 新增后端私有配置存储与认证 API：`/api/app-proxy/profiles`。管理员管理具名 YAML、授权用户、默认 `rule/global/direct` 与组选择；普通用户只能列出和读取已分配配置。bootstrap 不带 YAML，元数据只包含安全名称、修订、摘要、默认策略及有界组信息。正文单独认证 GET，no-store，禁止重定向，修订绑定避免内容/元数据竞争。
3. 管理状态不混入现有用户数据库；采用独立私有文件、原子写入、串行更新及写入前重新验证会话/权限。限4MiB、标准安全 YAML 解析和结构/组数量限制，错误不回显原文。管理员不自动分配给所有人，首次需要显式导入和授权。
4. Android 使用 bindScope 已验证且仅内存保留的当前服务凭据请求固定 API，下载正文直接进入原生校验与 AtomicFile，不把 YAML/token 返回 React，不把登录凭据发给任意订阅地址。保存 profileId/修订/摘要/策略与本地组覆盖，按服务来源+实例+用户隔离。
5. 首次导入使用服务器默认；日常更新保留仍有效的本地选择，显式“同步服务器策略”恢复服务器值。模式及节点在本地持久保存，启动先以真实 Mihomo 组清单验证并应用，再开放网络；失效节点安全回退。服务器元数据变更和配置修订均可检测。登录及前台恢复检查更新；运行中只提示，不暗中重启。用户应用更新时受控停止/验证/原子替换/恢复，失败保留旧配置，不能自动重发模型推理。
6. 原有文件/文本/匿名订阅入口保留。新增清晰的服务器配置选择、更新/同步策略、当前来源与模式控件；管理员另有上传/编辑/按账号分配入口。跨账号和服务的晚到列表/导入/状态结果不展示或落盘。失去授权可停止被撤销的服务器配置，离线不能宣称即时撤销。

## Impact

修改登录连接初始化及 Android 插件注册；新增代理服务端模块/路由/客户端 API 和管理 UI；增强 Android 代理状态、策略持久化和应用设置。桌面原生代理保持现有行为，服务器管理功能在已登录 Web 管理员中可用。

## Risks

会话仍会过期或被管理员撤销。原生安全写入失败不能伪装已保存。新服务器配置需要管理员导入，不能把任意本机订阅当成可共享配置。运行代理更新可能中断当前请求，按钮明确说明并不自动重试。真实手机未连接，模拟器证据不能替代小米实机。任何生产后端更新须先备份、fresh idle、数据与守护进程后验；不推广正式客户端。

## Verification Plan

Node API身份/竞争/401/离线恢复与跨端旧行为；Java vault/权限/原子文件/损坏密钥与代理持久化；后端管理员/普通用户/修订/撤销/超限/会话失效/并发；Android bridge 和 UI旧响应隔离；TS/Vite。模拟器实际登录、force-stop、重新打开、退出不复活；真实 Mihomo 合成配置、固定API下载、不外泄token、保存选择与模式、更新失效/坏配置回退。构建 APK 并验证旧版覆盖、签名、完整归档、许可与私有数据扫描；发布范围明确为开发候选。
