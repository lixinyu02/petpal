# Cubism V11 连续五官绑定

复杂度 L2。用户要求进一步补强真实 Cubism 模型，当前 V10 是真实 MOC/Core，但情绪主要靠局部贴图切换。本轮将独立眉、眼睑、虹膜拆层写入原生 ArtMesh keyforms 与 clipping masks。

## 目标与边界

- 保持当前奶油白与浅橘人物、脸型、眼睛大小、刘海、身体及合拢双手。
- 眉高/眉角、独立眼睑开合、受裁切的虹膜视线连续插值；情绪使用已有 performance 意图。
- 仅局部补画眼睛/眉毛下的皮肤，源图五官机械拆层。旧整脸表情贴图不进入新版。
- 嘴部继续使用已验证 A/O 局部朗读贴图，本轮不宣称独立唇形或 Editor 手工精修。
- 保留原生头部、手部、衣袖和发梢动作、TTS 驱动、减少动态及隐藏逻辑。
- 用户在实施中追加：修复动作突然切换，按头部/手部等区域区分鼠标和触控回应，语音输入期间保持倾听动作。与五官绑定一并验收，保留双击/长按/键盘行为。
- 先网页。无需安装包、后端重启、账号/API 配置或更新清单变更。

## 实现

新资产目录 V11 与 reference-features profile。原始身体、头发、嘴部层保持；新增眉、眼白 aperture、虹膜、上下睫毛层。新部件均在相同参考 head frame 下，避免自动语义 rig 改变脸型。虹膜只平移，眼白决定真实 MOC mask；眉毛小幅刚性运动；上下眼睑以多档原生几何插值闭合。旧表情参数曲线从动作文件过滤并重新统计。

## 风险和回退

最大风险是拆层边缘、重影及眼睛比例变化。先静态拼合对照，再真实 Core 与 Chrome 检查，视觉未通过不改默认。资源放独立版本目录，V10 可回退。Frozen authoring compiler 和 Core 不修改。

## 验收

1. PSD 像素/层读回，独立素材与来源记录。
2. 真实 Core 连续采样，参数真实存在；iris/brow 局部位移和 eye-mask，脸型、刘海及身体无意外变化；无 NaN 或动作虚拟参数。
3. runtime回归、TypeScript/Vite；Chrome 中中间眼睑、左右wink、语音嘴形、情绪衔接、412×960与冷启动。
4. 静态部署备份和公网文件哈希；不改后端服务状态。源码审计后单一 scoped commit/push。
5. 头部与手部区域按实际 contain 的人物坐标命中；悬停停留/移动反馈不反复重启动作；离开、取消及隐藏清理。ASR 连续文字不重触发倾听入场，倾听结束和手势结束平滑退场。
