# 人物及客户端边界回归

- Date: 2026-10-03
- Complexity: L1
- Scope: 当前 V12 运行时、鼠标/触控交互、表情与语音切换，以及相邻客户端状态；只修复可复现问题。

## 检查与修复方式

先运行人物相关已有回归，并行只读检查资源生命周期、交互状态及客户端边界。用隔离的 Chrome 页面加载真实 Core 和 V12，测试快速切换、卸载、加载失败、窗口 resize、语音阶段变化、休息唤醒及键盘/触控取消。发现问题后补最小复现和回归，再做最小实现修复。

隔离构建后才上线网页，保留当前首页回退；发布包版本与字节不随网页修复替换。不会将浏览器模拟或归档检查作为 Android/Ubuntu 实机验收。

## 验收

已有回归和新增复现用例通过；TypeScript、隔离生产构建通过；Chrome 检查真实渲染和无残留的事件/状态；已确认的问题、修复范围与尚未实测的边界记录于 issues。

## 最终实现

采用共享动作意图与命令消费记录交接原生/备用渲染器，避免 GPU 失效或重建覆盖休息状态；共享 Core/Framework 下载保留，单个 canvas 可以独立取消等待并释放 GPU。交互同时在画布移动后刷新，并在延迟动作执行前验证当前热点，使动画帧暂停时也不会使用旧位置。

相邻客户端仅修正下载架构顺序及存储 getter 拒绝的兼容性；完整回归暴露的测试等待条件按实际异步事件加固，不改变产品取消规则。验收结果及 Web 部署/客户端包边界见对应 issues。
