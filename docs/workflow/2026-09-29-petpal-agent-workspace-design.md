# Chat / Agent 工作台迭代

- Date: 2026-09-29
- Complexity: L2
- Status: final

## Background

0.6.2 可聊天、切模型、朗读，但模式入口分散，访客仍可进入角色空间并调用本地朗读。Agent 被固定为 owner 与受限桌面工具，缺少权限档位、追加引导、队列和图片。手机二次元渲染需要资源、着色器与回退路径复核。参考用户指定的 Codex Remote 源码和 Codex 0.143.0 本地协议，不照搬新版协议假设。

## Goal

登录后统一显示 Chat / Agent 工作台。Agent 在同一入口选择执行主机，清楚显示访问范围、审批方式、运行状态、引导与待执行消息。图片可随两种模式发送；登录后提供 Android / Windows / Ubuntu 下载入口。修复手机二次元角色可见性。

## Non-goals

不把手机或普通网页变成宿主机，不将远程后端伪称为手机本机，不替用户执行验证用的破坏性命令。不公开上传图片或私有服务凭据；不修改 RK3566 固件工程。

## Solution

### 登录与账号

SessionRoot 在 `/auth/me` 验证通过前只挂载登录入口，失败显示重试/登录，不挂载语音、设备、聊天或任务界面。语音 hook 自身拒绝无身份调用，退出/切服务取消旧任务与音频。本机配对仍需明确选择本机管理员入口。原有后端 bearer、来源校验和用户归属保护保留；所有新增 API 放在认证之后。被动 native 悬浮角色不具备服务任务入口。

Agent 授权独立于 owner：管理员可授予工作区访问或完整主机访问，默认不授予。成员不能修改全局 Codex 密钥/工具配置。撤销权限立即终止相关任务和队列；执行、审批和引导重新检查身份与会话归属。用户已明确选择给现有 test 授予远程 Agent、完整访问和自动运行；部署时仅为此账号应用该授权，其他账号保持原权限。

### 工作台和执行主机

显式 Chat / Agent 分段切换；选择模式开启对应新对话，保留旧会话。模型弹层提供名称、模型 ID、协议、搜索与选中状态。Agent 使用同一个编辑器，执行位置为本机或已登录的远程服务。浏览器/Android 只能选择远程；桌面通过内置后端使用本机，也可登录远程。每个服务保存独立会话凭据，切主机清空旧界面与请求，绝不把一个主机的令牌发送给另一个主机。既有会话绑定原执行主机，切位置进入该主机的会话列表。

权限分为访问范围（只读 / 工作区 / 完全访问）和审批方式（操作需确认 / 自动运行）。服务器将经过授权的参数传入实际 CLI；完全访问提示可读写主机文件与运行程序，自动运行提示审批影响。默认只读与需确认，不默默沿用更高权限。权限快照随会话/任务保存；运行中不能改变权限后再将旧队列升级。

### 引导、队列和图片

通过 `turn/steer` + `expectedTurnId` 向当前 Agent 追加引导；排队消息按序执行，展示状态，可取消，停止当前任务不会偷偷启动后续任务。失败、登出、撤权、服务切换时明确取消或暂停队列。队列保留身份、目标和权限快照，限制长度，不能跨账号接续。重启时遗留运行记录标记中断，不自动继续执行。

图片经认证上传，检查 MIME/魔数/大小/数量，保存用户归属的随机 ID 文件；历史仅公开附件元信息，通过有认证的请求加载预览。Chat 根据 Responses / Chat Completions 转成各自多模态格式；Agent 只引用服务器受控附件路径，不接受客户端本地路径。错误可见，不能悄悄丢图当纯文本发送。

### 角色与下载

二次元资源加载失败、WebGL 不可用、纹理过大或上下文丢失时显示同一角色的可见回退与重试，保留轻量动画。手机优先使用适度纹理和像素密度，不以桌面模拟尺寸冒充真机证明。

下载中心在登录后的导航中，列出三平台实际已发布的资产、版本、文件类型与安装方式；APK 侧载、Windows portable EXE、Ubuntu tar.gz 解压启动包分别说明。服务端固定可信仓库与资产模式，不能由用户任意提供 URL 代理下载。GitHub 本身是公开仓库，登录门禁约束小伴内入口而非声称 GitHub 公共资产是私有文件。

### 界面设计

- 视觉：延续奶油白、浅橘伙伴与低饱和绿的安静工作台，主要操作清晰，少装饰。
- 内容：顶部模式与执行位置；正文对话；底部图片、权限、引导/排队；侧栏历史、下载、账号。
- 动效：模式指示滑动、模型弹层短淡入、队列状态切换；遵守减少动态效果偏好。

## Impact

涉及前端认证根、角色渲染、工作台/设置、客户端连接会话、服务端账号/附件/任务/发布 API、CLI 配置与协议桥。旧用户、会话和模型配置迁移默认保持最低权限；构建产物和生产私有配置不进入公开源码。

## Risks

完整访问是明确的宿主机操作权，受授权与会话限制，不等同于用户文件系统隔离。原版本缺少服务器队列，需测试流断开、完成与引导竞态、撤权与排队竞态。客户端服务器选择不得转移凭据。手机版浏览器图形能力差异需要回退，最终仍需用户手机验收。

## Verification Plan

按 issue 顺序验证与提交。认证绕过/本地语音、附件隔离与多模态线格式、CLI 权限映射/steer、队列取消与撤权、模型/主机切换分别有针对性测试。Chrome 验收登录门禁、手机宽度、模式模型弹层、图片、队列和下载。真实模型/语音做有限无害连通检查；完整访问不运行危险测试。通过后更新线上前后端，必要时重新打包三平台，公开源码审计、签名/资源/下载哈希核验。

官方协议参考：https://learn.chatgpt.com/docs/app-server ，实现以 bundled 0.143.0 生成 schema 为准。
