# CosyVoice 朗读接入与公网访问

- Date: 2026-09-28
- Complexity: L2
- Status: updated

## Background

用户要求试用指定局域网语音服务、接入小伴并提供公网使用路径。实际服务是 Gradio 5.4.0 / CosyVoice，`/gradio_api/call/generate_audio` 为队列 SSE 接口，现无预训练音色。小伴现有远程 TTS/ASR 仅保存配置，朗读仍为系统 speechSynthesis。

## Goal

完成可验证的 CosyVoice 合成、账号认证后的音频代理、前端试听/回复朗读与播放期间的近似口型同步；使用现有账号和公网后端入口。管理员配置唯一可信上游和参考声音，成员可选择使用且不接触上游凭据。

## Non-goals

不将 TTS 当作 ASR；不引入任意 URL 代理、任意上游文件下载、后台自动录音或语音克隆任意人物；不改动已发布 v0.6.1 标签/资产，不把源码验证称为四端新包发布。

## Solution

- 服务器维护管理员专属 CosyVoice 配置与参考 WAV；默认未启用，无个人地址/音频写入公共源码。`GET /api/voice/cosyvoice` 返回可用状态，管理员可 `PATCH` 地址/参考文本、`POST /api/voice/cosyvoice/reference` 上传有上限的 WAV。参考文件存入私有 dataDir，通过应用生成的文件名读取。任何用户都不能传入任意本机路径。
- 原有每账号语音设置新增 `tts.mode=cosyvoice`，保留 system 和原 remote 预备配置；用户控制语速，成员不能修改共享上游。
- `POST /api/voice/synthesize` 只接受文本，使用当前账号配置。管理员配置的固定上游接收 reference upload 和 generate_audio 的十参数请求；非流式 zero-shot，解析队列 SSE 终止事件，再读取同源 Gradio 音频文件。禁止重定向、限制文字/响应体/音频/总时长/并发和调用频率，所有上游原始错误、路径和凭据脱敏。
- 返回 `audio/wav` 原始字节，不暴露上游文件 URL。请求断开、会话撤销、账号停用、服务退出会取消本地请求；Gradio 已开始的 GPU 任务不承诺物理取消。
- 前端复用带认证及账号切换保护的请求作用域获取 Blob；播放到用户选择的扬声器，结束/停止/页面隐藏/账号切换时终止 fetch/audio 并释放 Object URL。播放时按时间进度驱动角色嘴型，明确为近似同步。设置增加 CosyVoice 配置、参考音频和试听入口，ASR 仍明确未接入。
- 测试使用合成的中文参考声音，仅作示例；真实音色待用户选择后替换。若实际服务器合成失败，不以成功的 HTTP/队列回包冒充音频生成成功。

## Impact

新增后端适配模块、受认证路由、私有参考文件和语音配置模式；更新前端设置与朗读播放逻辑。默认系统朗读保持兼容，不自动为全部账号开启远程朗读。

## Risks

该 Gradio 当前无登录保护且可上传文件，公网优先复用小伴认证路由，不能直接开放其裸端口。现有域名端口的 LAN 回环不等同外网验证；如无独立外部网络，明确标记外部验证限制。公网 HTTP 不能称为 TLS 加密，HTTPS/证书条件需据实际部署说明。参考声音上传限 WAV/体积/时长且只接受管理员操作，未知来源文件和服务器返回 URL 均按不可信输入处理。

## Verification Plan

使用受控 Gradio fixture 测 SSE/错误/超时/取消/越域/超大音频；路由验证未认证、普通账号管理拒绝、账号隔离、限额和注销撤销。前端测试播放/取消/会话切换/设备输出/口型进度并完成 build。Chrome 验收实际设置与试听；真实生成 WAV 必须有有效头、非零时长/样本和下载证据。公网核查现有转发及匿名401，不暴露原始Gradio，源码扫描避免提交私有配置/音频。
