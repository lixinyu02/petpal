# Agent Remote 对齐验收

日期：2026-10-15。基线 `cf51021`，参考只读 `E:/codexsdk` 的稳定 HEAD `d11c59d`。

## 实现与边界

- 待执行队列可上移/下移，独立 queueRevision，完整排列 CAS；运行中的任务不重排。
- 只有原生 turn/steer 精确 method-not-found 才回退队列；网络中断和不确定送达不重发。
- unknown 任务和 uncertain 指令可逐项人工确认解除；保留队列与暂停，不重派原任务。未知项未全部解除时不能提交或继续执行。
- 显式修复 CLI 上下文可保留网页历史、草稿和图片，清理旧绑定并采用当前配置；不把旧指令自动回放给新 CLI。
- 原生 request_user_input 提供有界问题、显式回答/跳过、刷新恢复和原任务路由。停止、到期、撤权和连接结束使请求失效；回答回执不明时不重发。
- Chat + Agent 后台任务可展开处理提问和审批，不跳转或提交主聊天草稿。
- 审批遵守单次批准能力及请求支持的拒绝/取消值；具有绝对有效期。固定 CLI 0.143 没有 writeStdin 审批 kind，该分支仅完成前向兼容合成测试。
- 远端双方协商 userInput 能力；旧端不接收新命令。新增审批字段在旧中央端前剥离，保持旧协议兼容。
- 私密回答先完成 thread* 清理的持久化屏障，再送到原执行任务。本轮结束不重新绑定原线程，下轮明确提交新建 CLI 记忆；失败写入不会发送答案，旧快照也不能恢复该绑定。
