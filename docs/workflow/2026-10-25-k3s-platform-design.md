# K3s 平台接入

- Date: 2026-10-25
- Complexity: L2

通过现有 Docker Platform 一次性配对协议连接 K3s 执行节点，参考 Codex Remote 的 `docker_platform_kubernetes.py`。小伴不持有 kubeconfig，不直接调用集群管理员 API。原有用户、平台 client、项目、执行主机及 requestId 归属保持。

目录仅投影有界的运行时与能力字段；未知或损坏的运行时声明不可降级成 Docker。K3s 必须明确选择节点、仅 full/Agent CLI 模板、节点 PID 限制和持久存储确认后才允许创建。资源申请支持 CPU/内存，PID 自动使用节点固定值。首次申请前持久冻结参数；重试沿用同一项目和请求，节点能力改变时拒绝改写历史申请。

UI 显示 Docker/K3s 类型、在线/待配置状态、资源选择与不可用原因。K3s 不显示图形桌面入口。平台绑定沿用管理员服务配对，普通用户仅操作自己的环境。

验证包含目录异常、资源边界、冻结/重启/未知投递、账号隔离、HTTP/WS 执行与取消、组件事件、构建，以及实际平台配对和节点探测。真实集群未就绪时记录具体缺项，不把协议测试等同于真实 Pod/模型验收。发布前保护正在执行的记忆提炼及其他业务，不能为重启强行停止任务。
