# 远程 Clash 配置导入

- Date: 2026-10-15
- Complexity: L1
- Status: final

## Background

应用代理已有本地 YAML 导入与手动启停，需要支持用户服务器托管的配置链接。

## Goal

本机主账号在应用代理设置中输入 HTTP/HTTPS 地址，下载并经真实内核校验后导入；可手动从已保存来源重新下载。保持默认关闭和现有系统网络边界。

## Non-goals

不托管代理订阅、不设置后台定时更新、不转换 Base64 节点订阅、不改变系统代理；本轮不发布正式客户端或修改在线升级清单。

## Solution

主进程下载，限制 URL 格式/长度、协议、重定向、总超时和解压后的 4 MiB 正文。支持局域网 HTTP 与可信证书 HTTPS，拒绝 URL 用户名密码、片段及 HTTPS 降级。请求不带小伴登录凭据、Cookie 或 Referer。新链接导入及已保存来源更新均要求可信窗口和当前本机主账号，在异步下载/校验/保存前后重新鉴权。

远程来源 URL 与时间作为小伴生成的首行 YAML 注释，与规范化配置一次原子写入私有 config.yaml。导入内容本身的注释全部丢弃，再生成来源头；本地文件/文本导入清除远程来源。向界面仅返回 remoteConfigured、remoteUpdatedAt，不返回 URL、原 YAML 或令牌。运行中的代理需先关闭才能更换/更新配置。失败不覆盖当前配置及其来源。

## Impact

增加受限下载模块、manager 远程来源管理、可信 IPC/preload/API、设置表单和手动更新按钮；打包必需清单包含新模块。

## Risks

首次未启用代理时下载依赖直连；服务器返回登录页、Base64 或无效 YAML 会被拒绝。远程 URL 可能含订阅令牌，因此仅本机私有落盘、不写日志或状态。HTTP 不保证传输保密，界面允许它以支持用户局域网服务。

## Verification Plan

本地 HTTP 服务器实际下载，覆盖重定向、错误状态、限流式大小、超时、错误 UTF-8、HTML/错误 YAML、取消与身份变化；验证失败保留原配置、来源持久化/清除及不泄密；真实 Windows x64 内核与原生界面验收，生产构建和相关回归后自审提交。
