# Cubism V10 局部表情扩充

- Date: 2026-10-02
- Complexity: L2
- Status: done

## 背景与目标

用户继续要求更多表情。V9 有十六组动作，但真正的局部表情只有 Warm/Sad/Pout。本轮新增害羞、惊讶、安心三套实际脸部素材和原生参数，保留已认可的人物身份、脸眼比例、刘海、身体和合手姿势。

## 方案

用内置 imagegen 从原中性图编辑三个表情来源，再仅提取同坐标局部脸部到 V10 PSD；旧十一层逐像素保留。新增 reference-expressions 作者 profile，继承 V8 的手部绑定和共享头部变形器，三个新图层位于眨眼／嘴型之下。真实导出新的 MOC/CMO3，复用 V9 十六组动作。旧版本目录不可覆盖。

运行时只对真实存在的参数绑定：ParamShy、ParamSurprise、ParamRelaxed。表情竞争时只保留主导脸部层，口型和眨眼继续覆盖局部；旧模型保持旧参数合同。现有文本和播放边界负责触发，保留上游情绪优先级、停止／隐藏／睡眠清理。

## 影响和风险

生成图可能漂移，需逐张检查、只使用局部、对照原中性和最终 Core 渲染。新脸部层交叠可能重影，检查过渡与闭眼、A/O嘴型组合。不得借此修改旧模型资源或突破动作数量预算。

本轮不修改后端服务、账号配置、安装包或升级清单。CMO3 官方 Editor roundtrip、真实语音服务和实体客户端仍不属于本次验收。

## 验证和交付

单 issue 内分工完成资产、作者绑定与运行时。校验 PSD 读回、旧层像素、真实 Core 参数／层级／几何、情绪互斥和口型优先、旧模型兼容；运行相关回归及 TS/Vite。Chrome 插件检查六套表情、动态切换和 412×960。静态部署后读回公网哈希、保留后端与下载边界，审计公开源文件后提交推送。

完成结果见 [V10 验收](../cubism/facial-expressions-validation.md)。实测发现 Core 首次公网下载的 2.5 秒预算过短，同 issue 内改为有界 12 秒并补充慢下载／超时／重试测试；最终无缓存网页加载通过。
