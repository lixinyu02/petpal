# 账号记忆深度测试

- Date: 2026-10-25
- Complexity: L1
- Status: completed_with_known_boundary

## 目标

在既有账号隔离审计和88项定向回归之外，验证并发、多回合事实更新、持久化重开、中央/PC组合及真正模型回答中的记忆引用。重点保护zut账号既有记忆，不把测试事实写入正式账号，不重启或重配线上服务。

## 方法

确定性测试使用真实MemoryService和隔离目录，上游替身用于可控迟到、故障与并发。真实提炼测试使用当前Memobase与模型连接，每次使用随机实例/用户派生的自有命名空间，先确认不存在，只按本轮owned名单清理，并保留失败和清理回执。Chat端到端使用隔离PetServer、合成账号、真实记忆和模型，区分摘要读回与实际回答是否引用。

仅重开本轮创建的服务对象或隔离服务器验证恢复，不停止生产容器。测试正文和连接凭据保留在私有诊断目录，公共报告只含计数、布尔结果、耗时、代码证据和边界。发现缺陷先建立最小复现，明确既定语义后修复；不通过改期望、删除失败证据或盲重试取得通过。

## 已确认的开关边界

组合测试确认中央与PC开关各自生效，同步快照未传播enabled。中央关闭不能阻止PC在其本地开启时离线召回或继续录入同账号事实。它不属于串库，但尚不满足账号级统一暂停；本次只建立可复现的characterization和独立未通过记录，不贸然把既有协议改成新开关策略。后续实现需明确中央同意状态、本机偏好、断网和重启时的持久化门禁以及恢复启用流程。

## 验收

新增测试与现有相关回归通过；真实提炼、偏好更新、跨会话和模型回答有明确证据；账号和epoch隔离保持；正式zut journal在无真实用户并发操作时SHA保持；本轮所有随机上游投影清理确认。未测试的实机断网、移动系统生命周期等单列，不扩展为四端完整验收。
