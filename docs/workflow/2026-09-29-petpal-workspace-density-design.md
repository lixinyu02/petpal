# Agent 验收与工作台空间整理

- Date: 2026-09-29
- Complexity: L1
- Status: updated

## Background

用户要求检查真实 Agent 任务，并在验收期间指出当前 UI 过于拥挤。截图 evidence/agent-live/ui-before.png 显示执行电脑、模型、连接说明、队列、权限、语音状态上下堆叠，消息区被挤压；Chat/Agent 入口还重复出现在侧栏与主区。

## Goal

保留一眼可见的 Chat/Agent 切换、模型与执行电脑选择。将消息区作为主体，权限和辅助说明逐层展开，审批与失败保持醒目。真实完成只读终端任务、审批、队列和上下文验收。

## Non-goals

不改变账号权限、默认模型、Agent 执行策略或既有历史；不重新制作四端安装包。没有在线桌面电脑时，不把隔离测试当成远程电脑实机通过。

## Solution

- 视觉主张：延续奶油白／低饱和绿，信息集中、呼吸感充足，消息内容优先。
- 内容安排：紧凑顶部上下文栏、独立消息区域、简洁输入区；模型、主机、任务状态各出现一次主要说明。
- 交互主张：权限摘要展开选择、语音选项按需展开、连接帮助渐进披露；不隐藏运行、审批、错误和停止按钮。
- 运行中队列保持可见计数与暂停状态，展开查看／编辑条目，避免挤压消息区。
- 中等宽度可收起伙伴栏；手机保持清晰的模式／模型入口、可触控操作，不允许消息区缩到近乎不可用。
- 只修改前端结构与样式，后端逻辑若实际发现故障再记录并处理。
