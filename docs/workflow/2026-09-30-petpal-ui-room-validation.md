## 操作验收

- 模型菜单正常展示账号授权的三个 Agent 模型；选择当前模型后关闭子菜单、焦点回到模型入口，设置父层保持。
- 权限子面板显示访问范围与运行方式；Escape 先关闭子面板，再关闭父面板，焦点回到外部入口。
- 模型搜索框按 Tab 关闭子菜单并进入父层的权限入口。
- 点击遮罩关闭设置，焦点回到入口。
- 验收发现 Chrome 的 closed details 内 select 仍可返回布局 rect，初始焦点过滤因此误包含隐藏控件。已按祖先 details 的 open 状态及可见性过滤，并实测末尾 Tab 回到关闭按钮、首项 Shift+Tab 回到权限 summary。
- 自动派发保持关闭，权限保持只读／需要时询问；未发送消息或派发真实任务。
- 语音面板开启后立即停止采集，仅验收布局；模型 select 未被禁用。结束后退出本轮测试登录，并重置 Chrome 视口覆盖。
