# V11 轻触眨眼修复

- Date: 2026-10-03
- Complexity: L1
- Scope: V11 原生 Cubism 轻触头部时的眼睑参数合成；不改变模型资产、版本和 0.9.7 冻结安装包。

## 问题与原因

眼睛属于现有头部区域，单击会触发 `pet → TapHead`。该分区符合当前交互设计，本次不新增热点。TapHead 继承旧贴片模型的双眼曲线：Open 在 0.38–0.78 秒保持 0.26，直到 2.65 秒才完全恢复。V11 已改为连续眼睑，因此这个旧曲线会持续压窄双眼；运行时又将其与表情/自然眨眼的 Open 相乘，进一步放大闭合。

## 最小变更

仅在 `reference-features` 的 TapHead 及其淡出队列存在期间，让实时眼睑控制器拥有双眼开度，取消旧 TapHead 眼睑的乘法叠加。仍保留温柔表情和自然眨眼，以及完整原生头部、身体、合手动作。Wink 的右眼独占控制、其他原生动作、V10 和导入模型行为保留。

不修改 MOC、纹理、动作 JSON 或参数范围，不增加额外眨眼定时器。现有闭眼素材形状不在本次修复范围。

## 验证与交付边界

使用官方 Core 和原样 V11 模型/完整动作验证：轻触期间不再长期压窄眼睛；自然眨眼和朗读嘴型仍有效；头手动作持续；TapHead 淡出无残留。以 V10 的同动作作兼容性回归，运行人物/Cubism 相关测试和 TypeScript。网页实际点击与 412×960 视觉验收由主任务完成后记录。

0.9.7 已冻结安装包、版本号和 Release 文档不随这次源码修复自动改变。提交、网页部署和是否重新打包由主任务统一处理。
