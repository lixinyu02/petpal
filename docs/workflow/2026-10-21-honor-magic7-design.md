# 荣耀 Magic7 深度适配

- Date: 2026-10-21
- Complexity: L1
- Status: final

## Background / Goal

在既有 Magic8 的通用原生 insets/IME、主题、可见视口基础上，适配荣耀 Magic7 系列。用户补充要求标准版与 Pro 均适配，覆盖 Android15/16；还需识别真实系统/手机，隐藏其他厂商专属设置。覆盖系统显示缩放、横竖屏、手势/三键导航、切口、大字体、输入法及荣耀后台提醒设置；制作独立测试 APK。

## Solution

一个完整适配 issue：复用布局和原生唯一安全区消费者，不按机型强制分辨率或缩放。按官方规格建立测试矩阵（标准1264×2800；Pro1280×2800），用实际 WebView CSS 宽度验证。查找可复现的遮挡、裁切、滚动和动画负担再修复；后台设置采用已知 OEM 固定组件、实际 resolve/export 检查及系统兜底，不自动改权限。原生 Build 公开字段提供品牌、型号、Android版本/API，MagicOS版本无可信公开API则不猜测。界面仅展示当前平台/厂商适用控制，旧客户端缺失元数据仍可使用通用入口；不按UA或屏宽推断手机型号。默认不改刷新率、动画比例、网络、认证、代理或用户数据。

## Boundaries / Risks

不替换正式升级清单，不部署无关服务，不改硬件工程。普通安卓模拟器可以验证 API/布局与真实键盘/通知行为，不能冒称 MagicOS 真机菜单或长期后台留存已通过；如有真实设备连接先识别再使用，不更改用户手机设置。

## Validation

Chrome 插件验证登录、伙伴、聊天/Agent 选择器、语音、每日陪伴及设置；原生任务专属模拟器覆盖目标物理尺寸、多档密度、系统栏、IME、返回键、横竖屏和 textZoom；OEM route 单测/无真实设置修改验收；相关 TypeScript/Node/Java、构建、APK CRC/签名/16KB 对齐与资产审计。现有代理/认证与业务数据保留。

## Result

已完成原生设备/Android版本识别、当前厂商指南与可用入口筛选、HONOR现代管家候选和安全兜底、安卓不适用的本机中央服务器控件隐藏；现有布局通过两OS/两尺寸/多密度的验证，无需新增机型尺寸硬编码。独立测试APK已审计，216项JS、107项Java、36项原生运行验收通过，详见2026-10-21-honor-magic7-verification.md。未替换正式版本、未部署或修改业务服务。
