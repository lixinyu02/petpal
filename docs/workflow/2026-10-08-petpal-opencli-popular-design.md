# OpenCLI 常用网站查询扩展

- Date: 2026-10-08
- Complexity: L1
- Status: updated

## Background

通用 `petpal_browser` 已允许任意 HTTP(S) 网站。用户要求继续适配常用网站；包内模块不等于已开放的快捷查询。现有浏览器 facade 不支持上游部分模块的滚动、新标签及长等待，不能直接将库存命令全部标为可用。

## Goal

新增知乎、微博、豆瓣、京东、淘宝、小红书、抖音七站的固定查询，共十一项：知乎/微博热榜与搜索，豆瓣电影/图书榜及 Top250，其他四站原生搜索。输出有界、结构化，并提示登录、验证和未加载。

## Non-goals

不新增下单、发帖、关注、私信或自动登录。通用网页能力保持全站访问。本轮更新本机网页/后端，不重新发布安装包。

## Solution

复用明确选定的 Chrome 档案和每次查询租约。以服务端固定 builtin 脚本适配已审阅的上游路线与 DOM；知乎/微博仅放行三个确定的只读 GET API 路径。不向 Agent 提供脚本、cookie 或自定义执行参数。DOM 有界等待实际条目，识别可见登录墙/验证页，不把空列表当作热榜成功。返回来源链接，商品价格与数量仅为当前页可见值。目录和设置自动呈现真实命令参数与登录要求。

## Impact

浏览器政策、固定 adapter、设置说明、回归测试与使用文档。账号隔离、权限审批、远程执行电脑与取消/关闭机制沿用现有实现。

## Risks

网站可能要求扫码登录或验证码，页面结构和 API 可能变更。不得自动绕过；逐站记录真实内置工具的成功与受阻结果。不得用 Chrome 插件读取成功替代内置工具验收。淘宝/抖音/小红书标明需要登录。

## Verification Plan

验证 schema/源地址/请求路径/参数转义、ID 精度、去重与输出链接、登录墙/验证码/空结果/延迟加载。运行相关 OpenCLI 回归、TypeScript、保留 dist/downloads 的生产构建。逐站执行真实内置工具；Chrome 验收设置目录显示。本机服务仅在无任务且进程身份一致时更新，保留账号、会话、配对和下载。
