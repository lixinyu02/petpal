# 小伴启动、下载与日夜主题优化

- Date: 2026-10-04
- Complexity: L2
- Status: final

## Background

当前 3D 小猫已默认关闭，但旧设备显式启用记录仍能恢复。客户端下载目录已有 0.9.7 正式包，下载目录接口仍依赖 GitHub。首屏静态导入了部分工作台功能，服务全局 no-store 也让带哈希资源重复下载；当前只有浅色界面。

## Goal

本次升级使旧设备也默认回到二次元伙伴，减少登录及首屏加载成本，优先从同站点服务器下载最新正式包，并支持自动、日间、夜间主题。

## Non-goals

本轮不重打客户端，不修改既有 0.9.7 发布资产、签名更新清单或 Cubism 模型。浏览器性能证据不能代替 Android、Ubuntu 安装包启动验收。保持账号登录和权限边界。

## Solution

使用一个集成 issue，独立文件模块可委派并行实现，统一集成、审查和验收。

- 小猫能力记录版本迁移：旧开启记录失效，主窗口与浮窗都默认二次元；不删除原始账号人物偏好。只有新版设置中再次明确开启才可使用小猫。
- 测量当前首屏和构建体积，设置、下载和 Markdown 渲染按需加载，原生任务提醒仅 Android 入口延迟挂载，语音解码器在请求前延迟加载。HTML、版本和 API 保持不缓存，内容哈希 JS/CSS 长缓存；未版本化人物资产只允许重新验证。公开静态文件启用 gzip，API 流和安装包不压缩。人物布局的自然样式保留在入口、位于自适应规则之前，避免延迟样式覆盖网格尺寸。
- 同站点本地正式包目录使用发布清单、固定允许文件名、版本、长度与 SHA256 验证；优先返回实际存在且已校验的本地链接。保持仅最新正式版，元数据异常不回退旧版本，不接受任意代理 URL。GitHub 保留合理备用；离线服务器清单可独立工作。
- 本机主题偏好默认自动，设备本地时间 07:00–19:00 日间，其余夜间；可手动切换。启动前应用主题避免闪白，跨时间边界、页面恢复与跨窗口同步。暗色覆盖登录、伙伴、工作台、设置、下载及输入菜单，保持透明桌宠浮窗。

## Impact

涉及 React 入口、人物能力、本机外观设置、下载 API 与静态缓存。无需账号数据库迁移；网页及后端部署后即时生效，既有客户端需要后续新包。

界面视觉保持奶油白与柔和浅绿，夜间改为低亮度中性背景和清晰文字。内容仍以伙伴／聊天工作区为中心。交互沿用克制的按钮反馈、柔和人物动作与主题变化，尊重减少动态效果偏好。

## Risks

严格防止旧猫记录及旧浮窗地址复活、未登录资源触发业务操作、本地缺失包假链接、最新版回退旧包、哈希内容被错误缓存和主题污染透明浮窗。后端部署前确认没有活跃 Agent 任务，保留私有备份与回退入口。

## Verification Plan

能力记录迁移、主题时间边界与生命周期、下载文件完整性/缺失/恶意文件名、缓存与认证接口回归测试；TypeScript 和生产构建；完整串行测试。Chrome 优先验收公网登录、日夜主题、下载来源及 412×960 无横向溢出；记录冷/暖加载和体积边界。部署检查公网资源哈希与本地下载安装包 Range/HEAD，保持 V12 模型和既有正式包不变。

## 验收结果

- 完整串行回归 1711/1711，通过后仅修正人物 CSS 加载顺序；修正后 TypeScript/build、主题与原生浮窗同步 18/18 及实际浏览器再次通过。
- 最终构建工作台静态 JS/CSS 874,147 → 693,791 bytes，减少 20.63%；伙伴首页减少 5.87%。统计不包含 Core、模型与纹理。
- 本机 Chrome 公网登录页单次冷测：JS/CSS 实际 HTTP 传输 330,943 → 100,692 bytes，减少约 69.6%；首次内容绘制 624 → 284 ms。缓存后 JS/CSS 传输为 0，首次内容绘制 124 ms。这是本次网络和浏览器观察，不代表所有设备或安装包启动耗时。
- 公网五份最新正式客户端 HEAD 200、长度一致、Range 206且前64 bytes与服务器文件一致；六份正式资产本机完整 SHA256 一致。旧版根下载地址404、下载中心API未登录401，签名更新目录保持。
- Chrome 412×960：默认旧猫记录回到 anime，伙伴画布379×598.8、没有角色切换小猫入口；日间/夜间/自动切换、下载EXE/ZIP与x64/ARM64选择、Chat/Agent和模型弹层无横向溢出。当前版本无产品脚本错误，测试账号未提交新任务。
- 后端经精确进程/守护任务、Agent/队列/ASR与本进程TTS连接空闲复核后恢复，业务状态与凭据字节不变。正式安装包、升级清单与V12模型保留。静态入口 SHA256 为 `7a51bae20cb339bcdaab76e41bab2dda8093253b0ed7e7a6232d1b324b7c69b0`。
- 证据位于忽略目录 `evidence/fast-start-20261004/`。本轮没有重打客户端，旧客户端内置前端需后续新版包；Android/Ubuntu实机启动不在本轮验收范围。
