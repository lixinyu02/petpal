# 单只 3D 小猫持续陪伴

- Complexity: L2
- Date: 2026-09-26
- Status: implementation

## 用户目标与纠正
用户需要一只持续活动、可以互动的小猫，不接受多动作卡片展示或 GIF 轮播作为最终桌宠。外观已确认软萌橘白 3D 卡通小猫，允许必要时采用 UE5。

## 实现决策
采用 Three.js WebGL 的单一立体角色与实时光照，在 Web、Electron Windows/Ubuntu 和 Android WebView 共用渲染器。角色由连续节点动画控制头部、眼睛、耳朵、尾巴与四肢；所有状态使用同一模型，不切换角色图片。独立状态机控制自主待机、走动、用户抚摸、进食、跳跃、明确休息/唤醒。UE5 暂不引入；此交互范围无需大型引擎，Web 共用渲染与移动常驻资源控制更优先。

## 视觉与交互
视觉：一只橘白圆脸小猫作为唯一主角，奶油色空间、柔和光影、绿色项圈。主页面只有陪伴场景、简短状态与抚摸/喂食/休息操作，聊天与 Codex 为进入工作台的独立入口。旧四格展示入口指向新的单猫场景。
小猫呼吸、眨眼和摆尾；视线跟随指针。空闲时在有限地面范围走动、回头；点击/触摸会抚摸，双击小跳；动作平滑返回待机。睡眠保持到主动唤醒。页面隐藏暂停，恢复时不追赶失去的帧；减少动态效果设置停止自主走动与大幅动作。

## 平台与边界
Windows/Ubuntu 继续由 Electron 管理透明置顶小猫、本地服务和真实 Codex CLI。Android 前景悬浮服务使用本地透明 WebView 渲染同一模型，只加载 APK 内静态资源；没有后端访问或任意 JavaScript native bridge。独立原生拖动把手与聊天按钮保留。Web 主页面可独立玩小猫，聊天仍走已有鉴权与配置。

## 风险与验证
WebGL 不可用时明确呈现可重试提示，不伪装成 3D。限制像素比、帧率和几何精度；释放纹理、几何、监听器与 context。状态机做有意义的边界/睡眠/交互打断/hidden/reduced-motion 测试。Chrome 插件验收同屏一个角色、真实 WebGL、动作交互、响应式和页面恢复。Windows 便携程序验证真实 3D 窗口及 CLI；Android/Ubuntu 重新构建并核对资源，但未执行实机验收时仍明确记录。

## 用户建模反馈
初稿的狭长耳、外凸多层眼球、白色颊球/胸球和分段前臂让角色偏离猫科比例。按用户反馈优先修改模型结构：宽基短三角耳、贴合脸面的浅曲面眼区、内建口鼻体积、贴图白毛区、连续前腿与蜷坐后肢。修正后检查正面、侧面和睡姿，不以换引擎替代造型修复。

## 版本与交付
版本更新为 0.2.0，保留 0.1.0 包和旧素材作为历史；新应用入口不再展示旧动画列表。原有后端、供应商协议与 Codex 合同不变。交付新原生包、源码与校验清单，不触及 RK3566 实板。

## 新增二维伙伴（用户确认）
用户在建模修正期间新增需求：保留小猫，另加 Live2D 风格二次元人物，确认温柔日系少女、奶油白与浅橘配色。复杂度仍为 L2，纳入 issue-3 同一渲染与四端集成范围。默认显示二次元伙伴，通过首页切换至 3D 小猫；任意时刻只有一个活动角色和画布。两者共用聊天、模型连接和真实 Codex 后端。

视觉：原创成人少女半身立绘、轻柔发丝、暖色针织日常服，保留安静奶油色空间。内容：角色切换、单一主角、状态短句、摸头/点心/休息，聊天和 Codex 入口不变。交互：呼吸、平滑转头跟随、局部眼睛眨动与闭眼、口型回应、头发轻摆，隐藏时暂停，减少动态设置停止持续形变。

实现为自有二维网格变形渲染器；原始、闭眼、开口三张生成透明 PNG 通过面部局部遮罩组合，身体不切整幅帧，40×60 网格控制头部/发丝/胸部。它不是 Cubism `.moc3` 模型，不包含 PSD、Cubism Core 或第三方模型；`CompanionScene` 独立适配入口可后续接正式模型，当前不宣称支持导入。参考研究与许可证据见 `docs/avatar-research.md`。当前口型为交互/文本流动画，不是音频级唇形同步，也未新增 TTS。

偏好：`settings.companionKind` 精确枚举 anime/cat，默认 anime；本地选择缓存支持离线，Electron 窗口通过 storage 更新。Android 由受限 native 参数选择固定本地 overlay URL，仍不暴露 JS bridge。
