# 性能、界面与图标细化

- Date: 2026-09-30
- Complexity: L1
- Status: investigating / implementing
- Baseline: f423860，接续 issue-48/49。

## 目标与取舍

视觉沿用奶油白与森林绿，统一图标为圆角线性图标；宽屏消息和输入采用适合阅读的列宽，手机操作保持清楚。界面围绕聊天内容、任务控制和人物三部分，不新增装饰面板。

交互使用按钮短暂颜色/箭头反馈、按需显示的阅读操作和既有人物动作；遵循减少动画偏好。模式、模型、电脑、审批、停止、语音和附件入口保持可达。

性能优先解决可复核的负担：人物 PNG 传输体积、非当前角色的同步依赖、语音播放时重复派生和历史侧栏协调。角色资源若转换为无损 WebP，必须保持 RGBA 逐像素一致、透明边界和尺寸，并保留原作者源图于非 public 目录。先量化再决定，不用压缩指标代替低配设备帧率。

不修改 SSE/语音分句、Agent 排队/权限/审批、账号隔离或后端数据。暂不更换 React/Electron 或用 Rust 重写。

## 实施和验收

issue-50 先完成资源与运行时性能，再由 issue-51 细化 UI/图标并上线网页。针对实际修改运行有意义的资源/调度/生命周期回归、TS/构建；Chrome 优先，验证桌面、412×960 和短屏、长历史、模型/模式、人物切换、停止和键盘阅读。

隔离构建和固定回复数据，生产仅替换静态文件；保留旧资源、下载镜像和 HTML 回退，检查公网 hash、health 和匿名门禁。按 issue 提交并推送，网页先上线，本轮不重打四端安装包。
