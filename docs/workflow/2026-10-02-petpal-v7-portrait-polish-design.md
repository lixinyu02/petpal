# Cubism V7 观感美化

- Complexity: L1
- Status: done

## 目标

在已上线 V7 的原脸、五官、刘海和几何绑定上，改善人物展示与动作观感。美术方向是奶油白和浅杏的柔和光感，人物为主，页面留白简洁。保留 412×960 自适应、透明桌宠及现有语音口型。

## 方案

增加仅作用于内置 V7 的轻微色彩对比和轮廓投影，调整首页人物背景光与信息层级；不修改 MOC、原画像素及贴图坐标。入口淡入、轻触反馈和安静待机构成动效，减少动画偏好关闭装饰过渡。

原生 Idle 与 performance 均有眨眼时钟，当前相乘会产生靠近的连眨。仅在 reference-layered 下让 performance 拥有待机眨眼，互动队列保留其真实闭眼曲线。待机曲线放慢至原来的 0.75 倍时间、角度幅度 0.7 倍；指针和互动不缩放，语音口型保持实时，隐藏／休息继续立即归零。原生互动淡出期间不得被待机倍率影响。

## 验收

用真实 Framework 队列与 MOC 对照日常眨眼、互动过渡和立即闭嘴；运行相关回归、TS 和隔离构建。Chrome 对照原效果与美化页，验证 412×960、桌面、直接点击、透明边界与减少动画偏好。通过后按既有授权只更新网页，保留后端、账号、下载及旧资源；源码公开审计后提交推送。

223 项角色／语音相关回归和新增 4 项真实 Core／Framework 测试全部通过，TypeScript 和隔离 Vite 构建通过。Chrome 正式网页已确认原生 Cubism、V7 专用样式、桌面及 412×960 无横向溢出；本地预览轻触、正式页键盘 TapHead 和减少动画模式均有实际证据。
