# 二次元伙伴自然动作与语音衔接

- Date: 2026-10-01
- Complexity: L2
- Status: final

## Background

用户希望继续改善二次元人物动画，可必要采用 VTuber 套件。当前角色是八张同角色 WebP 的局部表情混合与 Three.js 2D 网格，不具备 Cubism 分层模型、moc3 或 VRM 骨骼。现有动作与 TTS 口型已联动，但视线、头、胸肩共享即时目标，缺少自然的跟随层次；逐字边界清空口型及能量变化重算点头相位可能造成不连续。

## Goal

视觉保持奶油白与浅橘的同一人物，动作温柔、克制、连贯。先看向交互位置，再轻微转头和跟随胸肩；呼吸与发梢有不同时间尺度，说话时细微起伏，直接触摸保留回应。前台语音与表情继续独立驱动嘴型，不添加拥挤的动作按钮。

## Solution

新增不依赖渲染器的 presence 控制器，以有界阻尼弹簧分别驱动眼、头、上身，并积分呼吸相位；WebGL 和 DOM 使用同一输出。现有 semantic gestures 和 emotions 仍拥有表情/口型，presence 不读取或改写文字和音频队列。发根、面部、领口及手保护区保持，头发响应实际头部姿态。将实际 PCM 播放的换字 cue 与强制闭嘴分离，停止/静音/隐藏仍立即闭嘴；语音点头改为积分相位。

低动态、睡眠、隐藏立即清除额外动作；恢复时从中性平滑启动，不追补隐藏时间。沿用八个采样器与当前贴图，不增加摄像头权限或跟踪开销。桌面、412×960、DOM 降级和真实浏览器朗读都要验证，隐藏页面不保持 RAF。

## VTuber choice

研究官方 Cubism、pixi-live2d-display、MediaPipe/Kalidokit 与 VRM。套件不能把现有整幅立绘自动转为完整 rig；当前迭代采用轻量人物驱动，记录接入真正分层 Cubism 模型的资源及许可要求。已有用户角色、账号、语音参考及运行任务保持，不引入未经验证的样例角色或默认摄像头跟踪。

## Delivery and verification

新增有意义的稳定性、停用、帧率一致性与说话边界回归，复验相关 avatar/voice/scene-loop 测试、TypeScript 和隔离 Vite build。Chrome 插件检查真实动作与截图；预览测试用隔离数据，不调用真实 Agent 或音乐工具。通过后只推广网页静态资源、原子替换 HTML，保留旧资源和回退 HTML，不重启后端、不变更 0.9.6 安装包或签名更新清单。记录部署前后生产数据与下载资产保持、可信公网资源读回，完成 issue-72 源码提交。
