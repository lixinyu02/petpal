# 同账号桌面执行电脑

- Date: 2026-09-29
- Complexity: L2
- Status: final

## Background

当前“此电脑 / 远程主机”切换整个后端，不能列出同账号登录的电脑。用户明确要求由登录 PC / Ubuntu 客户端识别执行电脑，Web / Android 选择执行位置，账号与聊天记录保持不变。

## Goal

桌面登录后自动注册稳定设备标识、真实电脑名、平台和在线状态。任务按所选电脑执行；队列、插入指令、审批和停止均固定到原执行机。中央保留用户、模型、图片和聊天；退出登录停止接单。保持现有中央后端执行选项以兼容旧会话。

## Non-goals

不开放电脑入站端口，不增加管理员配对密码，不把网页声明的客户端类型当作授权，不分发中央模型密钥，不自动转派离线任务，不迁移任意本机文件。旧桌面安装包不能自动获得新执行器。

## Solution

### 登录和设备生命周期

Electron main 持久化随机 deviceId，读取 hostname/platform/arch。渲染层在验证中央登录后调用专用 executor.connect({url,token,instanceId,userId})；main 再次向中央验证身份，token 只在内存。同一中心和账号下设备 ID 对应稳定 hostId。重新注册轮换 connectionId，旧连接不得续租、取任务或提交事件。主窗托盘隐藏继续运行，注销、切换账号/中心和退出客户端关闭运行与连接。浏览器/Android 不注册执行器。

### 反向任务协议

电脑主动经认证长轮询领取固定 schema 的 run/steer/approve/stop 命令，上传有序事件和完成回执。每机最多一个活跃运行；租约过期在线状态消失。命令 ID、runId、connectionId 共同界定执行；执行前保存领取记录，重复 ID 不重放。网络状态不明时暂停队列并呈现“执行状态未知”，不声称已经停止。断线后的未知任务不会自动重试。正常停止等待执行器确认，超时明确未知。

### 账号、模型与图片

中央对控制端会话和执行端会话同时校验，复用用户 Agent 权限上限。主机清单只对所属账号开放。每次运行提供短期且限定 host/connection/run/model 的 Responses relay 凭据，中央持原模型 API key 并固定上游；运行完成、过期或撤销即失效。执行器不能下发任意可执行文件、环境或工作目录。图片仅来自当前任务已授权附件，经尺寸、类型、长度校验后传输并写入账号隔离目录，不接受任意 URL 或中央绝对路径。执行器使用真实内置 CodexBridge 和桌面工具，工作区及 Codex 数据按中央 instanceId/userId 隔离。

### 聊天和选择行为

新增独立 agentHostId 选择，不调用 setConnection。任务入队时冻结 hostId；运行后捕获 bridge 与 connectionId，steer/approve/stop 不重新查默认 bridge。中央消息历史保持原会话；切换主机时不能 resume 旧电脑 threadId，使用新 thread 加有限近期文字上下文。新 thread 记录所属 hostId。运行期间禁止改目标，排队条目标明目标电脑。旧无 hostId 数据按中央执行机解释。

主机选择器展示电脑名、平台、在线/离线、此电脑提示；无在线桌面时说明“在电脑客户端登录同一账号”。离线主机不能新提交，不静默回落到服务器。Agent 引导跟随所选主机能力，模型仍使用中央授权列表。

## Impact

涉及 server 的执行器注册、relay、任务路由、存储兼容和公开投影；desktop 的登录生命周期与后台 worker；src 的账号同步、选择器和任务快照。HTTP 兼容现有受控来源配置，公网部署继续使用 HTTPS。原 Chat、CosyVoice 流和账号配置应保持不变。

## Risks

防止跨用户执行/附件访问、旧连接复活、重复执行、跨电脑 threadId、过期凭据和进程遗留。中央重启/客户端崩溃不能证明子进程停止，UI 必须明确未知且不自动重放。源码完成不等于已安装客户端更新，交付需包含新桌面构建与实际验收边界。

## Verification Plan

验证两台独立执行器身份选择实际接收的命令、跨用户拒绝、会话撤销、旧 epoch、命令重复、离线暂停、真实 CLI 路径、relay 密钥隔离、图片/steer/审批/取消、中央历史不变。运行相关测试、全量测试、TypeScript/Vite 构建，并用 Chrome 验证主机列表、手机布局和历史。受控部署先备份并保持账号/模型/语音数据，生成桌面交付包；未实测的物理 Ubuntu/Android 环境明确说明。
