# 默认伙伴与远程 PC 执行体验

- Date: 2026-09-30
- Complexity: L1（沿用现有执行器/账户/权限协议，若发现协议风险再提升）
- Status: in_progress
- Baseline: 0529534

## 目标

默认只显示二次元伙伴，3D 小猫改为设置中的手动启用选项。优先采用按账号/服务隔离的本设备显示开关，不删除模型、不批量改用户历史设置；浮窗遵循有效显示形象，不让旧猫偏好在默认关闭时提前加载 3D。

执行电脑入口清楚显示此电脑、其他在线电脑、中央服务器和离线状态；Agent 与 Chat + Agent 保持一致。明确选择过的离线电脑不得自动切换到别处；正在运行/提交状态保持锁定，普通聊天记录不随电脑切换改变。

实际验收 PC 客户端的登录注册、认证 HTTPS 长轮询/心跳、Codex app-server 和远程任务。先检查已发布 Windows 包与当前执行电脑，再用隔离 Windows 客户端 profile、同一账号及无副作用的只读 Codex 任务完成公网端到端证据。模型/设备不可用时报告具体阻塞，不把 fixture 在线替代真实 CLI 执行。

保持鉴权、账号隔离、权限与审批合同，不开放 PC 入站端口，不输出凭据。若修复涉及桌面原生代码，准备可交付新包；单纯网页/UI 更新不重做安装包。按 issue 顺序提交，完成网页与公网验收后推送；只操作 PetPal，禁止触碰 RK3566 固件。

## 验证

默认猫加载/跨账户/浮窗与切换回归，主机分组/离线/锁定/触屏/键盘检查；TypeScript、定向后端与执行器回归、Chrome 1280×800、412×960。真实 PC 任务记录 hostId/connection、CLI版本/完成状态与只读结果，保留私有证据并清理自身 profile/进程；不改其他人的客户端或运行任务。
