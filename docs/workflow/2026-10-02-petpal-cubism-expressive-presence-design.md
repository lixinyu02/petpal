# Cubism 神态与场景动作增强

- Date: 2026-10-02
- Complexity: L2
- Status: done

## 目标

继续当前 V8 的人物形象、脸发比例与真实合手骨架，增加能在实际对话触发的动作和微表情。默认发布 V9 动作包；MOC、纹理与物理原样复用 V8，保留旧目录。不存在新的独立眼球、眉骨、手指或手臂绑定，不用位移整张脸模拟它们。

## 方案

V9 原有九组动作保留，再加入 Curious、Think、Listen、Surprise、Reassure、Wink、Doze 七组原生曲线，总共十六组，遵守现有资源数量上限。利用已有头身、合手、衣袖和局部闭眼参数，保持幅度克制；闭眼曲线不控制嘴型或竞争整脸表情贴片。

语义动作根据好奇／思考、惊讶、安慰／放松、倾听、困倦、俏皮等意图选择。思考和倾听阶段仅入口触发一次，不能因每帧更新或语音分片重复执行。增加低频待机侧头、双眨眼、呼吸停顿的组合，保留长安静间隔。手动互动优先，停止、切换阶段、隐藏、休息和减少动态不留积压。原生动作淡出期间保留关节归属，口型仍归实际播放。

## 验证与发布

一个 issue 内并行负责动作资产、调度桥、语义与微表情，最后整合。以真实 Core／Framework 验证新动作、关键形范围、口型隔离、回位与旧 V7/V8 兼容；验证阶段去重、打断、负面情绪、低动态与长帧。Chrome 插件预览实际曲线、生产布局 412×960；TypeScript、相关测试与 Vite 构建通过后仅更新网页静态内容。部署保留业务数据、后端进程、下载包和升级清单；来源及哈希公开审计后提交 GitHub。

## 边界

不重绘人物、不重打安装包、不改变模型/API/权限配置。不把模拟语音动作宣称为实际 ASR/TTS 重测；官方 Editor roundtrip 与实体客户端外观仍保持未验证。

实现及验收已完成，结果见 [V9 验收](../cubism/expressive-presence-validation.md)。
