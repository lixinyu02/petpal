# 服务与聊天稳定性调优

- Date: 2026-10-23
- Complexity: L1
- Status: final

## Background

本机 4318 未监听，公网返回 502。原守护任务结果为 0xC000013A，只有登录触发和有限重试；退出发起者尚不能确认。启动既有任务后健康恢复，state.json 字节哈希保持。

聊天停止接口只按会话查当前任务，旧停止请求延迟到达时可能停止下一轮。

## Goal

守护进程退出后具有持续恢复入口；恢复状态以真实健康检查为准。旧回复的停止请求不能取消新回复。

## Non-goals

不改路由、账号、模型、更新渠道或客户端版本；不重打安装包，不自动强杀健康异常进程，不声称长期零故障。

## Solution

按 issue 顺序处理。将既有守护实现纳入仓库，保留进程身份、端口、维护标记与互斥保护，增加健康巡检和周期任务恢复；启动回执原子发布。先以隔离测试验证，再更新本机已有任务。聊天停止请求携带本轮身份，由服务端核对，旧客户端兼容路径保留。

Chat 每轮发送 clientRequestId，停止携带 expectedRequestId，仅存储在活动任务内存中；不匹配立即返回 stopped:false。文字与语音均捕获原请求身份，普通LAN HTTP使用加密随机字节生成兼容UUID。旧客户端省略身份时保留 stop-current 行为，Agent 队列停止不变。

## Impact

服务部署脚本、本机既有计划任务及 Chat 停止协议。业务数据结构保持，已登录用户权限保持。

## Risks

周期恢复不得接管未知监听器或绕过维护窗口；检查超时不得导致误杀。旧停止请求的兼容行为需要回归；前端异步回调须继续遵守账号隔离。

## Verification Plan

Windows PowerShell 5.1/7 隔离生命周期测试，任务配置与单实例验证，本机及公网健康、匿名鉴权、数据保留；Chat 迟到停止请求回归、TypeScript、生产构建及 Chrome 网页验收。
