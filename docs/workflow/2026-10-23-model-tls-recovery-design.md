# 模型 HTTPS 连接恢复

- Date: 2026-10-23
- Complexity: L1

## 问题和证据

小伴健康检查正常；最近 Chat 请求连接 CPA 失败。当前 Node 与 Windows curl 均在正常 TLS 验证下报告证书过期。8317 服务证书有效期止于 2026-10-22 03:01:14 UTC。另一 LAN 模型服务的 models 接口正常。

## 方案

1. 只读核对模型服务的证书来源与自动续期机制。优先复用同域名现有有效证书，通过备份、验证及受控载入恢复 CPA；保持 HTTPS 与主机名验证，不改模型和密钥。
2. 为 Chat 连接错误增加可操作的 TLS/DNS/连接错误分类，保留取消和超时行为，错误文本不泄露凭据。运行针对性回归并复验生产模型实际回复。

## 边界和验收

保留用户、会话、权限、代理、下载与更新数据。证书材料只存在服务器私有目录。证书检查不等同模型推理成功；必须通过正常 TLS 的 models 与实际流式模型请求。若需要重启只限确认的 CPA 进程，并提前确认没有执行中任务。恢复前像以支持回退。
