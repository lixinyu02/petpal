# 内置 OpenCLI 国内天气查询

- Date: 2026-10-11
- Complexity: L1
- Status: updated

## Background

用户需要国内可靠天气来源及具体地点查询。现有公开查询严格绑定 OpenCLI 1.8.8 manifest，新增项目自带适配器必须独立注册，不能放宽上游模块核验。

## Goal

接入中国天气网和中央气象台的公开地点目录与天气数据，共六项查询。中国天气网行政目录支持区县，官网 JSONP 搜索还支持有数据的乡镇街道；先搜索候选及真实 ID，再使用选中的 ID 查询。返回来源、地点精度、数据发布时间和抓取时间，避免同名地点误选以及把粗粒度预报称为街道实况。

## Non-goals

不申请收费 API、不自动定位、不上传用户地址、不设置周期任务。此次更新源码及可安全更新的本机服务，不重打已发布 0.9.11 客户端。

## Solution

增加固定 builtin-public 政策和 adapter，通过既有 petpal_opencli_sites/query 发现和执行。复用隔离 worker 的固定主机、无凭据 GET、25 秒取消、原始响应和输出长度限制。上游 manifest/registry 校验继续单独保持。地点搜索不自动选择第一项；天气明示空间与时间分辨率，缺失/旧数据不伪装成当前有效预报。Agent 工具说明加入查询顺序与精度边界。

中国天气网区县日/3小时预报分别保留 fc_24h 与 fc_3h 数据时间；乡镇分时预报采用 jf 完整日期，eventDay/Night 排除昨天。乡镇模板按浏览器时钟生成的更新时间不作为发布证据，published_at 保持 null，freshness=unknown。中央气象台使用当前省份目录中的不透明地点 code，不能猜 WMO 站号；实况、预报、空气质量各自时间独立。两个来源可能共用中央气象台数据，不称为独立数值模式。

## Impact

公开网站目录、worker、天气解析器、Agent 工具说明、使用文档和回归测试；桌面打包规则已覆盖 server/opencli*.mjs。

## Risks

公开网站结构和接口可能变化或被限流；源数据不等于准确性保证。不同网站发布时间、测站与区县范围不必相同。结果需保留各自的原始时间含义。

## Verification Plan

验证地点消歧、行政层级、城市 ID、结构异常、空值、更新时间、3小时/日预报及取消/网络范围。执行真实隔离 worker 联网查询，覆盖上海浦东、异地和同名区县；使用 Chrome 插件核对官方页面。完成相关 OpenCLI/desktop-tools 回归和按变更需要的构建检查。更新服务前核进程、在途任务和业务状态，保留原运行态证据。
