# 二次元伙伴动作增强

- Date: 2026-09-29
- Complexity: L1
- Status: updated

## Background

用户希望同一位奶油白与浅橘少女有轻微飘动的头发、更丰富自然的表情，并明确先上线网页体验、确认后再制作安装包。现有实现是单立绘网格和六张局部表情贴图。

## Goal

固定发根、保护脸与衣服，让左右发梢错相轻摆；增加开心、俏皮和关切反馈，使表情连续过渡。保留直接鼠标／触控互动、小手反馈与真实朗读口型。

## Non-goals

本轮不更换角色、引入 UE/Cubism、增加显式动作按钮、不发布四端安装包或新 Release。不声称已有录音状态联动或音素识别。

## Solution

- 视觉主张：温柔、轻盈、有回应的同一角色，动作集中于眼眉、微笑和发梢。
- 内容安排：保留现有工作台与角色位置，交互直接发生在角色上，不增添演示面板。
- 动作主张：左右发梢错相与轻惯性；抚摸后放松、招呼时短暂单眼回应；文字语义表情平滑衔接。
- 发束权重由独立可测试模块生成并作为顶点属性输入，发根、面部、颈胸不承受头发形变。左右位移有上限与缓动；睡眠抑制主动动作，减少动态时停止。
- 表演控制器提供独立缓动的表情通道，互动只影响表情，不改变音频／文字口型。嘴部朗读优先，停止、隐藏和休息时保持正确边界。
- WebGL 与 DOM 共享表情参数。DOM 复用 blink 素材分开左右眼，保留微笑与关切，头发保持静止，避免伪分层重影。

## Impact

主要影响 avatar 控制器、网格 shader、DOM 降级和相关测试。版本保持 0.9.0 安装包基线，网页以源码提交记录预览更新，不改原生版本、更新清单或签名。

## Risks

单图形变可能牵动衣服或造成发丝拉伸，需要实际截图／连续观察；表情不能打断朗读。不得向线上直接构建，部署使用隔离产物与备份，只替换前端静态目录。

## Verification Plan

发根／脸部保护、位移范围、平滑过渡、互动与语音并行、睡眠、减少动态与隐藏定向测试；TS／Vite 与必要回归。Chrome 桌面和窄屏检查局部头发、不同表情、手势、强制 WebGL 丢失后的 DOM。备份后部署网页并检查生产登录门禁、产物摘要和实际页面。
