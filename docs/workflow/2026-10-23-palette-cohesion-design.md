# 配色统一

- Date: 2026-10-23
- Complexity: L1

## 视觉与内容

视觉主张：淡白纸面、石墨色操作、温和中性侧栏，人物浅橘只留在角色画面中。深色沿用石墨背景，以暖白文字和浅色主按钮对应。

内容保持现有层级：聊天工作区是主体，导航和伙伴栏是辅助，模型/主机弹层与卡片使用同一套表面和文本角色。保留现有切换、悬停和面板入场动效，不增加常驻动画。

## 原因与方案

浅色 theme 定义未映射历史 `--green/--line/--soft/--cream`，全局文字和大量组件仍使用旧森林绿；伙伴栏有奶黄色背景，部分按钮已改为陶土橙，形成多套色板。统一主题角色与历史别名，迁移高频组件硬编码颜色，不改变布局、权限、模型或角色资产。

默认淡白和自动昼夜时间规则保持。复验对比度及 Chrome 登录、Chat、模型/主机菜单、OpenUI、深浅主题和412×960。构建后用现有入口图检查部署；保留下载、用户数据及旧资源。
