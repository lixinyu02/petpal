# PetPal 页面性能迭代

- Date: 2026-10-07
- Complexity: L1
- Status: implementing
- Baseline: 86dfc13，初始工作区干净。

## Background

已有按需加载、消息行memo、首字即时/50ms流式展示合并、rAF滚动合并、人物隐藏暂停。本轮审计发现人物30FPS门槛每次重置为now会丢弃余数；会话轮询的JSON快照整体替换未变化的消息引用，破坏已有memo并触发多余滚动和Markdown工作。

## Goal

修正人物绘制节奏；让Agent、自动化与Chat+Agent快照保留不变消息引用，降低长历史重复渲染。通过可复现前后对比确认收益。帧限速仍使用rAF，不将调度修正描述为减少rAF唤醒或GPU耗电。

## Non-goals

不修改模型资产、上游接口、审批/权限、SSE顺序、语音分句、账户数据、现有主题与人物外观。不替换React/Electron或Rust重写。本轮源码、本地构建与隔离浏览器验收，不部署、推送或重打安装包。

## Solution

共享可见场景循环承担可选maxFps调度：保存目标时间/余数，绘制elapsed仍由场景计算；隐藏、取消和迟到回调不能恢复旧循环。默认未限速行为保持，减少动画及互动语义保持，各场景删除旧now-last限速判断。

新增会话消息引用复用方法，匹配id并比较完整JSON消息数据；只复用确实相同的消息，保留上游顺序、删除、新增与所有附件/状态/模型等字段。相同消息序列复用旧数组，任务/项目等元数据仍使用权威快照。在会话快照合并处统一使用，保持未需合并时incoming identity合同。

## Impact

可见动画循环、Cubism/恢复人物/小猫场景；会话快照合并与App状态；调度/合并/界面行为测试和本地性能验收记录。

## Risks

帧间隔算法不能把回到前台的大间隔累计成补帧风暴；不能修改说话嘴型和互动dt语义。消息复用不能忽略嵌套字段、重排或权威删除；旧账号迟到响应与现有取消门禁保持。调度模拟和本机Chrome指标不能等同于各手机/客户端实测FPS。

## Verification Plan

比较相同60/90/120/144Hz合成时间戳的10秒绘制次数；取消、隐藏、恢复、减少动画与各场景集成回归。消息快照未变/末条变化/附件状态变化/重排/删除/任务状态更新覆盖，记录长历史复用数及真实TSX输出。TypeScript、隔离Vite构建、相关与全量回归、自审。优先Chrome插件，当前初始化超时需重试或用本机浏览器测试；桌面、412×960 CSS视口、Markdown/滚动/语音按钮/人物互动验收，明确本机与跨端边界。
