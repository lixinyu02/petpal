# Android 权限与系统兼容

- Date: 2026-10-23
- Complexity: L2
- Status: final

## Background

Android minSdk 23、targetSdk 35、compileSdk 36。已有通知/OEM 后台入口和本地媒体授权，但权限状态分散；WebView 共享媒体/附件权限回调，悬浮窗启动缺少前台生命周期门禁和设置回退。

## Goal

按功能提供可恢复的麦克风、相机、通知、悬浮窗、更新安装和后台设置，区分授权、系统总开关、通知频道与不支持。保持登录后操作、明确点击申请、当前厂商指南和四端兼容。

## Non-goals

不加入全盘存储、位置、通讯录、无障碍、VPN、后台录音；不批量授权、不绕过系统限制、不改正式下载源、账号数据、代理或后端运行配置。模拟器不替代小米/荣耀真机验收。

## Solution

1. 原生 PetPermissions 提供本地安全主页面的系统状态读取 status 和固定枚举 openSettings。状态包含硬件能力、媒体授权、传感器总开关（可读取时）、通知运行时/总开关/各频道、悬浮窗、独立安装来源权限、省电状态和设备身份。读取时只为新观察到的授权更新内部历史提示，不修改系统设置。设置只能路由到验证过的系统组件，失败回退本应用详情；不接受任意 intent/package/URL。
2. 媒体继续使用用户点击 getUserMedia；记录实际发起的权限询问，结合系统 grant/rationale/询问记录识别状态。取消请求后保留共享回调占位直至回调，避免附件/定位替换回调；拒绝未使用定位。处理异常、迟到结果和后台状态。
3. 悬浮窗复用可信页面/前台门禁，通知许可回调后等待恢复前台再启动，销毁/重复请求可取消。检查通知总开关和自身频道；设置页固定路由安全回退。保留停止入口。
4. 登录后的客户端设置添加折叠权限面板。初始及返回前台时合并刷新，账号 epoch/卸载隔离迟到结果。媒体测试只获取所选设备并立即停止；设置打开不当作已授权。现有 OEM 引导继续只显示当前厂商。

## Impact

只改 Android 原生桥、客户端设置及相关测试。旧客户端/非 Android 隐藏或提示升级，不影响 PC/Web。权限状态按系统实时读取，偏好不代替授权。

## Risks

系统一次性许可/自动回收与厂商设置可能变化；询问历史仅辅助引导而非授权依据。返回设置时 Activity 尚未恢复，需延后前台服务启动。保持本地主页面桥边界，远程 iframe/悬浮页不能打开设置或请求媒体。OEM 私有组件只作候选且运行时验证，不承诺真机支持。

## Verification Plan

纯策略/前端生命周期回归、TypeScript、Android JVM、打包和合并 Manifest 审计。隔离 API 33/35/36 模拟器（资源允许时顺序执行）检查初始/拒绝/重试/设置返回、通知频道和特殊权限入口；保留现有 AVD。产出独立 QA APK，不改正式版本目录。无真机时明确未完成 OEM 真机验收。
