# 参考 Codex Remote 的回复收尾与流式交互优化

- Date: 2026-10-22
- Complexity: L2
- Status: completed; source and isolated acceptance only

## Background

用户要求参考会话 `codex://threads/01a119c9-3aa2-7bf3-8659-eb58dcaa3782` 继续优化小伴。当前源码为 `bac9f47`，0.9.14 正式 tag 和已发布资产保持冻结。参考项目最新取证强调分开任务终态与后处理、保留 DOM 身份，以及用实际瓶颈选择优化点。参考仓库另有任务在工作，本轮只读，不修改其源码或服务。

小伴已有流式批显、历史行 memo、消息引用复用和16k/1.5s增量落盘，本轮不重复宣称这些功能缺失，也不移植未经验证的整库 debounce。源码和隔离 gate 已确认：Chat 已落盘的回复仍等待记忆日志才发送 done；Agent 记忆写入仍占用同会话锁；客户端收到终态还等待 HTTP EOF，之后又等待全量 /state 才解除 busy/触发朗读；Markdown 的内联组件定义使流式更新更换表格/链接组件身份；隐藏 Agent 页面仍轮询全文。

## Goal

让已持久化的完成结果尽快交付，用户能继续发送、听到朗读，Agent 下一条任务不等辅助记忆服务。减少不必要的 DOM 重建和隐藏页面刷新。保留停止、审批、账号切换、记忆删除、隐私保护、断线恢复及当前 Markdown 语义。

## Non-goals

本轮不重写 JsonStore、不修改现有恢复/审批持久化边界、不引入 OpenUI、不分割 Markdown 语法树、不重打客户端或改动0.9.14正式资产。性能数据仅使用隔离受控提供方，不能称为真实模型首字性能或实体手机验收。

## Solution

1. 将“终态已保存”和“辅助记忆记录”分开。共享记忆任务所有者负责冻结消息字段、去重、有界排队/并发、错误消费与关闭收尾。Chat 终态保存成功后交付结果；Agent 终态保存并释放执行/会话锁后启动下一条任务。记忆操作不持有前台响应或执行锁。
2. 后台记忆必须在实际落盘前重新验证账号、会话归属、消息存在/完成状态、敏感输入、取消和记忆epoch。记忆服务的可选 signal/authorize 扩展向后兼容；单任务取消不终止其他账号共享的远端验证。关闭先停接新任务，给予有界收尾时间，再取消未完成辅助任务，防止永久关闭挂起。拥塞和失败可在任务所有者诊断中观察，不能伪装写入成功。
3. 客户端读取到 done/error 后停止接收后续帧，清理读取器但不等待无界传输收尾。完整终态已经包含权威会话时不再次拉取整库。异常/中断只恢复目标会话，采用有界请求及账号epoch、请求序号校验，旧恢复结果不能覆盖新一轮任务或切换后的账号；朗读一次且不等待额外刷新。
4. Markdown components/插件列表使用模块级稳定身份，保留原有安全URL、禁HTML、图片占位及GFM语义，避免正文追加时表格横向位置/链接焦点重置。超长回复展示节奏以实测成本调整，第一段和显式终态仍立即刷新；不改变内容或Markdown跨块语义。
5. Agent 被动展示轮询复用可见/在线的单飞调度，恢复前台立即刷新；不会停止后台执行或原生通知。

## Impact

后端 app、agent-tasks、memory-service 及新增记忆任务所有者；前端 API流读取、Chat收尾、Markdown渲染和被动轮询。存储格式、登录协议、审批协议与正式包签名不变。新源码提交与现有正式版本分离，现有业务数据和生产服务不作为测试夹具。

## Risks

- 后台记忆不能在撤权/删除/清空后晚写回：必须在原子替换前使用存活/epoch/消息保护，不能只检查入队时状态。
- 旧 finally 或恢复请求不能清理下一轮的 active/busy 或覆盖消息。
- 收到明确终态才走快路；无终态断流仍报错并保留部分文本。
- 记忆是有界辅助工作；聊天历史先落盘。进入记忆本地journal前若进程崩溃，可能缺少该条记忆，本轮不新增outbox或修改存储格式。入journal后仍沿用现有持久同步/重试。
- 取消读取的 Promise 可能永不完成，清理不得再次阻塞输入。
- React 节点身份需真实 DOM 验收；SSR微测不能当作浏览器收益。

## Verification Plan

先用可控 gate 复现慢记忆、慢EOF和慢状态读取。针对 Chat/Agent 队列、关闭、记忆清空/撤权/账号隔离补行为回归；客户端覆盖done/error后连接不关闭、尾随帧、截断、取消/账号切换及旧恢复覆盖。Chrome插件优先，隔离服务验收连续发送、长Markdown表格/链接DOM身份、焦点和横向滚动、手机尺寸；插件确实不可用时采用独立Chrome/Playwright。执行类型检查、隔离前端构建及相关回归，记录实测样本和边界，保留失败证据，按issue提交。
