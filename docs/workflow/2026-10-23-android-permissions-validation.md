## 交付行为

登录后的客户端设置新增折叠“权限与兼容性”。麦克风/摄像头按需检查并立即释放，分辨首次授权、可重试拒绝与需系统设置恢复；通知总开关与任务/问候/后台监听/悬浮伙伴频道分别显示；安装来源、省电与悬浮窗权限独立读取。返回前台重新读取，切换账号/卸载/超时不接受迟到结果。

媒体与附件共用权限回调的争用已互锁；后台授权结果等待真实恢复前台，定位不请求。悬浮伙伴设置只走固定且验证过的系统路由，通知许可后等待前台再启动 FGS；检查通知总开关、频道和频道组。未新增任何 uses-permission；保留当前品牌 OEM 后台指南。

补测修复：系统设置中的手动授权没有 runtime 回调，读取到真实授权后会更新一次内部结果历史，避免后续一次性许可回收/自动撤权继承旧的重复拒绝状态。未自动申请或修改系统授权；相机运行测试检查了实际设置授权后的历史更新。

## 排查与边界

首轮发现并修正测试基础设施问题：AndroidX instrumentation Kotlin stdlib/jdk8版本冲突（仅测试依赖用BOM对齐，定向构建`:app`）；系统设置窗口过渡及 singleTask 夹具清理竞态；重复拒绝弹窗的不同按钮ID；WebView109的loadDataWithBaseURL data来源与旧/新Capacitor桥注入差异。保留失败日志和后续修正记录，未放宽产品的本地来源/前台门禁。

并行三台模拟器曾有一次API35夹具页面启动超时，保留 `api35-parallel-fixture-startup-failure.log`；关闭已通过的33/36后，以相同最终产品APK和测试APK独立复跑35全部12项通过。未把中间失败日志当成功，也未跳过用例。

同时发现原打包脚本 `npm run build -- --outDir` 将参数传到末尾验证器，Vite实际写到dist；两平台脚本已改为显式类型检查、指定目录Vite构建和对应目录验证。首次本轮构建因此写到dist，已恢复原发布入口 `index-CqGwi8nX.js`；后续使用隔离目录构建。没有删除dist下载。Vite的`.vite/manifest.json`是构建元数据且被AAPT排除：保留完整构建验证，另复制排除该目录的运行时快照做APK逐资源核验，不放宽资源审计规则。

普通应用无法从公开Android SDK可靠读取系统传感器隐私总开关，返回unknown并提示人工检查。OEM后台、自启动私有组件仅按运行时可用性安全跳转及回退；小米HyperOS/荣耀MagicOS真机与Android6–12运行态未验收。不能承诺绕过厂商杀后台、自动获权或静默安装。
