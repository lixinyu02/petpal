# 二次元伙伴微表演扩展

- Date: 2026-09-30
- Complexity: L2
- Status: completed

## 目标与视觉

在 issue-40 的同一位奶油白／浅橘伙伴上，进一步丰富 Galgame 风格的细微反应。安静陪伴时有低频的轻瞥、慢眨眼和浅笑；台词中的犹豫、困倦、期待、委屈与温柔使用不同眼眉、视线和姿态。产品继续使用直接鼠标／触控互动，不增加常驻表情按钮，先发布网页。

视觉主张是小幅、可辨识的情绪变化，不增加装饰或新面板。既有页面结构不变。动作主张是探身倾听、轻轻缩肩、礼貌低头、侧身探看、轻摆和困倦低头，均有自然收尾；不会把整个人物夸张拉伸或声称已具备独立手臂骨骼。

## 实现契约

- 新增表情 `hesitant`、`sleepy`、`expectant`、`aggrieved`、`tender`，控制器输出同名 Amount 通道。否定、情绪枚举与切句保持保守判断。
- 新增单次动作 `leanIn`、`shrug`、`bow`、`peek`、`sway`、`doze`。沿用既有 body/head 通道，新增有界 `shoulderLift`（0..1），原有动作默认 0。肩部仅小幅形变，WebGL/DOM 一致方向。
- 新增低频 idle 微表演 `microExpression` / `microProgress`：`none`、`glance`、`softBlink`、`softSmile`。只在 idle、无活动朗读、无触摸反应、可见且非 reduced motion 时运行；进入倾听/思考/说话或触摸即取消，无追赶补播。每轮间隔至少数秒，不用永久随机循环晃动。
- 表情和微表演不得覆盖嘴型或改变音频；实际 TTS 分句仍通过现有接口驱动。同句去重、冷却、低帧率 wall-clock、隐藏、停止、缓冲及睡眠边界保留。
- 使用现有八张贴图与局部眼眉变形；本轮不添加采样器或新角色素材。GL/DOM 共用视觉映射，口型最后叠加。

## 验证与发布

有意义的时序回归覆盖新语义、动作区分、idle 被打断、低帧率、口型不受影响和语义去重；渲染映射和资源测试、TypeScript、隔离构建。Chrome 使用 412×960 与桌面检查新表情、全部新动作、idle 细节、降级和触摸；测试面板仅本机。

原子替换网页 HTML、保留旧资源，校验公网资源与匿名语音门禁，核对账号/模型/聊天/语音数据保持。源码审计后提交并推送 GitHub；不制作安装包。TTS 服务等待外部恢复的边界不因视觉验收而改变。
