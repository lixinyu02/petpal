# 直接与伙伴互动

首页、聊天工作台和桌面悬浮窗共用同一套手势。角色本体可点击，透明空白不算命中。

- 轻触：回应；睡着时唤醒。
- 双击或连续轻点两次：打招呼，小猫轻跳。
- 鼠标按住并轻轻移动：抚摸反馈，连续操作有节制，不反复打断动作。
- 原地长按再松开：休息。移动、滚动、多指、取消或离开页面会取消该次长按。
- 键盘：Tab 选中角色；Enter／空格轻按、连按或长按，提供对应操作。

手机可以从舞台空白区域上下滚动。工作台缩成窄屏时，同一只伙伴移到顶部右侧，保留状态和草稿。休息时停止朗读，轻触伙伴唤醒后可继续使用语音。

## 角色表现

二次元伙伴沿用奶油白、浅橘色原画，使用分层图片与 WebGL 网格动画，并保留兼容性降级；不是 Cubism SDK 模型。此次降低整个人物摆动，微调视线、眉眼和接触反馈。触碰不会伪造说话口型；口型继续由真实回复文字或朗读进度驱动。

3D 小猫沿用橘白配色和原模型。跳跃与行为进度一致，起落及中途动作切换连续；尾巴、睡眠呼吸和减少动态设置的表现也已修正。

## 验收

49 项交互、模型、表情、资源及角色偏好测试通过，TypeScript 与独立 Vite 构建通过。Chrome 隔离环境验证两种角色展示、点击与键盘回应、触控长按休息、唤醒和空白滚动。桌面工作台休息后切至 390px，角色仍可触摸唤醒，未发送草稿保持原样。手机截图覆盖 390px 和 412px。

原始截图及临时测试账号位于忽略目录 `evidence/natural-companion/`，不随源码或安装包公开。浏览器触控模拟不能替代 Android 真机验收。

## 执行电脑与队列修复

桌面执行电脑临时断网后，会先关闭旧 CLI，再按 1、2、4、8、15、30 秒退避重新连接。重新上线不会重放原任务：无法确认的任务仍显示状态未知，队列保持暂停。账号失效、权限拒绝、协议或安装错误停止重试；注销或切换账号取消旧连接的恢复流程。

删除未执行队列任务只需要有效登录、会话归属和最新队列版本。电脑离线或模型配置变化不再阻止清理；新增、编辑和恢复任务仍检查执行条件。
