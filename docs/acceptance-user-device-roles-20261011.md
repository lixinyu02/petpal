## 已上线的规则

账号分为用户与管理员。普通用户的执行电脑列表直接隐藏中央服务器和其他账号的电脑；失效的历史选择不再合成列表条目，也不会自动换到另一台电脑。用户仅能选择自己账号登录的 PC，管理员可选择中央服务器和所有已登记设备，并看到设备所属账号。

全部有效账号可以使用 Agent。完整访问、自动运行和受执行器支持的模型审查由每次任务选择，账号不再按旧 Agent 分级限制。模型授权、对话归属、执行器连接凭据仍隔离。管理员可管理用户身份、密码、停用和模型；初始 owner 保留管理员身份。

## Chrome 界面

公网 test 页面显示“用户”，账号页无账号管理入口；Agent 设备列表无中央服务器，8 个条目均显示“我的电脑 · test · @test”。管理员页面显示“管理员”，有用户与身份管理入口；设备列表包含中央服务器和“所属用户 · test · @test”。管理 test 的窗口提供用户／管理员选择，本轮只查看，未保存身份或密码修改。

另按标签页实际模拟 412×960，页面 `clientWidth=scrollWidth=412`，设备列表仍仅自身电脑，无横向溢出。普通浏览器 viewport 设置首次未应用，原图保留并明确标为未应用，随后按标签页 CDP 模拟验证；临时尺寸均恢复。

当前 8 台 PC 都离线。普通用户可见完整访问和自动运行选项，但无在线执行电脑时控件不可提交；这是设备就绪保护，不是账号授权不足。本轮未通过生产 PC 执行系统任务、未验原生客户端重启／打包。
