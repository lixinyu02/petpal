# 语音链路稳定性复查

## 后台服务恢复

公网 502 的直接原因是小伴后端与 SSH 隧道监督器均已退出，HTTPS 反向代理仍在运行。检查确认工具进程属于带 `KILL_ON_JOB_CLOSE` 的 Windows Job；普通启动的子进程继承该生命周期。仅脱离内层 Job 后，外层仍保留退出清理限制，因此不能作为长期后台服务启动方式。历史日志未记录具体的进程终止调用，Job 机制是已验证的退出风险。

已新增当前用户计划任务 **`PetPal HTTPS current user`**，以 `Interactive` 登录类型和 `Limited` 权限隐藏运行既有 `Start-PetPal-HttpsTunnel.ps1`。任务由 Windows 任务计划服务启动，与工具进程父链分离；监督器再启动既有后端和 SSH 隧道。原有 **`PetPal HTTPS.lnk`** 登录启动快捷方式保留，没有修改账户、防火墙、TLS 或网络权限，也没有重启计算机。

验收确认任务处于 `Running`，监督器父进程为任务计划服务、窗口句柄为 0，本机与公网健康接口均返回 200。完成下述 ASR 测试后，监督器、后端和隧道仍在运行。该任务依赖当前用户的交互式登录；本次没有验证注销、重启或长时间连续运行。

这是 **3/3 次短音频链路验收**，不能等同于长期稳定性、多人并发或真人麦克风验收。

## TTS 剩余项

只读日志末尾显示 CosyVoice 完成关闭并退出；此后其 TCP 入口仍可连接，但 HTTP 请求被重置。现有管理入口只提供日志，没有服务重启功能。因此，健康接口此前偶尔返回 200 不构成合成成功证据。

当前等待语音服务主机通过既有方式启动 CosyVoice，或取得该主机的授权管理身份后恢复服务。恢复后仍须完成一次短句流式 TTS、完整音频校验和 ASR 转写闭环；本次没有把 TTS 标为恢复。

## 回滚后台启动调整

本次未修改既有启动脚本。需要撤销新增任务时，先确认没有正在执行的任务；停止计划任务会中断其托管的后端和隧道。

```powershell
Stop-ScheduledTask -TaskName 'PetPal HTTPS current user'
Unregister-ScheduledTask -TaskName 'PetPal HTTPS current user' -Confirm:$false
```

随后通过原有 **`PetPal HTTPS.lnk`** 登录启动快捷方式恢复既有启动方式。不要从临时工具进程直接启动长期服务，否则可能重新继承工具的 Job 生命周期。清理任何残留进程前应重新核对当前启动记录与进程身份，不使用历史 PID。
