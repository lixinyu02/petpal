# Android 登录保留与服务器代理配置

## 登录

Android 主页面会用系统 Keystore 加密保存当前小伴服务的登录会话，关闭应用或强行停止后，重新打开会恢复并验证身份。不会保存账号密码，也不会把会话放入系统云备份。

服务端会话仍有原来的有效期（七天），退出账号、管理员撤销或服务端返回当前会话 401 后需要重新登录。临时断网、服务超时和 5xx 不清除保存的会话；恢复网络后重试验证即可。

## 管理员分发

1. 登录 Web 或 Android 管理员账号，打开「连接与设置 → 设备连接 → 服务器代理配置」。
2. 添加配置，导入或粘贴 UTF-8 Clash YAML（最多 4 MB），勾选可使用的账号并保存。
3. 编辑已保存的配置，设置默认规则／全局／直连模式，以及各策略组默认节点。订阅 provider 的动态节点可以填写准确名称，手机运行内核会验证实际节点是否存在。

本功能不会自动读取、共享服务器原有的私人订阅。管理员须明确导入和分配。服务端只保存独立的私有配置文件，用户只可读取分配给自己的配置。节点或地区名称来自配置，界面不推断实际地理位置。

## Android 使用

在「设备连接 → 小伴应用代理」选择服务器下发的配置，点击「使用此配置」，再启用代理。可以修改运行模式和策略组节点，并选择登录此账号后随小伴启用。

- **更新配置**：同步新文件，保留仍然有效的本机模式和节点选择。
- **同步服务器策略**：同步文件，并恢复服务器配置的默认模式和节点。
- 登录、回到前台或手动刷新会检查更新；运行中不会自动重启内核。更新和切换按钮会说明重启行为，操作期间当前网络请求可能中断，不会自动重发模型任务。
- 服务器已明确撤销访问时会停用该配置；无法连接服务器时保留本机配置，离线不能即时得知撤销。

原有 YAML 文件、文本和 HTTPS 订阅链接导入保留在「其他导入方式」。订阅链接不携带小伴登录令牌。服务器配置由原生层从当前登录服务的固定 API 下载，不把 YAML 返回聊天页面。

代理只影响小伴自身联网，不申请系统 VPN，也不改变其他应用或外部浏览器的网络。各账号、服务器和配置的本机选择分别保存。当前这轮的服务器配置消费入口在 Android，Web 提供管理入口，桌面代理原有功能保持。

## 验收与安装边界

用户已要求正式发布。本轮正式包为 `0.9.13`（Android versionCode 25），沿用既有签名，可覆盖 0.9.12 和临时 dev.1／dev.2 安装。正式下载与双源升级清单在发布 issue-4 中验收，Windows／Ubuntu 保留各自已验收的 0.9.12。模拟器验证不等于小米 17 Pro Max／Android 16 真机验收；真机上可依次检查：登录、关闭重开、选择代理节点、关闭重开、退出账号后再重开。
